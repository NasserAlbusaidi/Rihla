# #704 — Trip Receipt: tamper-evident shareable proof pack (Slice A: data + CSV)

> Core slice of epic **#708 Settle & Seal**. Foundation shipped: payment handoff (#367), event close
> lifecycle (#723), spending snapshot freeze (#766), recap PNG card (#722). This slice adds the **data
> proof pack** the recap card omits — every expense, **per-person allocation**, settlements, corrections,
> per-currency balances — exportable as CSV.
>
> **v3 — after Gate rounds 1 & 2** (6-lens fresh-context panel + refuter each round). R1 killed the
> "fold an existing activity_logs stream provider, no new queries" framing. R2 caught two money/PII P1s:
> per-line allocations not reconciling with verbatim balances (#249 universe), and `payerChange`
> leaking raw UIDs. All confirmed findings folded in; changed items tagged **[G1]/[G2]**.

## Decisions (locked 2026-06-30, `decision`+`privacy` issue)

| # | Decision | Choice |
|---|---|---|
| 1 | Format | **PDF + CSV**, **CSV first** (this slice); PDF = Slice B |
| 2 | Scope | **Event-only** (recap screen) |
| 3 | Audit depth | **Final state + corrections/edits** (from `activity_logs`) |
| 4 | Offline | **Client-side**; data sections fully offline; **corrections best-effort, 3-state coverage stamp** **[G1/G2]** |

"Tamper-evident" = surfaces the server-recorded edits/soft-deletes (oracle-derived) **and honestly states
audit coverage** — not a cryptographic signature. No callable, no Storage SDK, no crypto-signing.

## What ships

1. Pure immutable **`TripReceipt`** projection (mirrors `EventRecap`). **Re-derives no balances**;
   per-expense allocation uses the canonical public allocator over the **same universe as the oracle**.
2. Pure **CSV serializer** (`package:csv`; l10n passed in for category names).
3. New **`ActivityService.fetchAllEventAuditLogs`** + a **`FutureProvider.family`** loading audit logs
   honestly (loading/error surfaced; coverage bounded; **DESC** order). **[G1/G2]**
4. Composing **`tripReceiptProvider`** → `AsyncValue<TripReceipt>`, **`AsyncLoading` until event doc +
   members + expenses + settlements + audit all resolve** (no false-empty *and* no false-complete). **[G2]**
5. iOS-safe **`shareCsv`** chokepoint.
6. **"Export ledger (CSV)"** CTA on the recap share sheet (→ `ConsumerStatefulWidget`, threaded `EventRef`).
   Gated on `AsyncData`. **No new route.**

**Writes NOTHING to Firestore.** No new field/schema/rules/callable. The only new *read* is the audit fetch.

## Critical constraint — no oracle re-derivation (principle 6)

- **Balances** copied **verbatim** from `ledgerViewProvider(eventRef).balances` — the single memoized
  per-event `calculateBalances` pass the ledger/hub/recap share (`ledger_view_provider.dart:54-55`).
  **NOT `groupBalancesProvider`** (group-aggregated = wrong universe). **[G1]**
- **Per-expense per-person owed** uses `BalanceCalculator.allocateExpenseOwed` — the SAME public allocator
  `calculateBalances` and the #591 ledger row use. **It MUST be passed the full balance universe**, i.e.
  `participantIds: view.participants.map((p) => p.id)` (the #249-folded `eventBalanceUniverse` —
  `ledger_view_provider.dart:95-131`). **Forbid `event.participantIds`** — a global/equal expense would
  divide over fewer heads than the oracle did, so the ALLOCATIONS section would contradict the BALANCES
  section beside it. **[G2 P1]** Reconciliation is pinned by a test (below).
- Only new arithmetic = **fils→Decimal display conversion** + **per-currency grouping**. Oracle parity
  (`calculateBalances` ↔ `recomputeNet`) untouched.

## Verified facts (re-checked against code this session)

- **No event-scoped `activity_logs` stream provider exists** (no `lib/features/activity/providers/`). The
  only reader is `ActivityService.fetchActivityPageRaw` — 50/page cursor `.get()`, `createdAt` desc, no
  eventType filter. A single page silently truncates corrections. **[G1 P1 → complete fetch + coverage stamp.]**
- `activity_logs` client-readable: `firestore.rules:903` (`isGroupMember(groupId) && module in [...'activity_logs']`).
- Audit money = `amountFils`(int)+`currency` in `ActivityLog.metadata.{before,after}`
  (`expenseAuditLogger.ts`; CREATE has `before:null`). **A soft-delete (DELETE) flips only `isDeleted` —
  amount/description/payer are UNCHANGED, so `before==after` for money** (`expense_service.dart:372-378`).
  `ExpenseAuditDiff.fromMetadata` exposes only `amountChanged/descriptionChanged/payerChanged`+`hasFieldChange`,
  all **false for a DELETE**. **[G2: DELETE must take its amount directly from `diff.after`, not via
  change-flags, or the deleted magnitude is lost — the single most audit-relevant fact.]**
  `ExpenseAuditSnap.payerParticipantId` is a **raw UID** (no name). **[G2 P1: resolve `payerChange` through
  the name() helper.]** `tryParse` routes through `MoneySerializer.fromSubunits`, which throws on an
  off-allowlist currency → wrap per-log parsing in try/catch (surface "unreadable entry", never drop).
- `MoneySerializer.fromSubunits/fractionDigits`; off-allowlist fallback = 2dp (RAmount parity;
  `formatCurrency` actually uses 3dp — don't cite it). Currencies are fenced to the 10-code allowlist at
  deser, so the fallback is effectively dead for live amounts. **[G2 P3 wording.]**
- `categoryNameForId(String? id, AppLocalizations l10n)` — **2-arg**; builder keeps raw `categoryId`, CSV
  layer resolves. **[G1.]**
- `ledgerViewProvider(EventRef)` is a **synchronous `Provider`** that ALSO watches `eventDetailProvider`
  + `groupMembersProvider` and returns a **defensive-EMPTY view (balances `{}`, roster `{}`, participants
  `[]`) when `event==null`** (`ledger_view_provider.dart:73-88`). Its emptiness is invisible to an
  AsyncData gate → the receipt provider must independently gate on `eventDetailProvider`(non-null event) +
  `groupMembersProvider`, else a false-COMPLETE empty pack. **[G2 P2.]** `.participants` = the
  #249-folded universe; `.rosterDisplayNames` = #196-disambiguated (` (#last4)`; terminal fallback
  `'Former member'`, never a uid). `MemberNameResolver.stripDiscriminator(String)` strips the discriminator.
- `eventDetailProvider` (`event_provider.dart:47`, keyed by `EventRef`, value `Event?`);
  `groupMembersProvider` (`group_provider.dart:623`, `StreamProvider.family<List<GroupMember>, String>` —
  **keyed by groupId**). `allocateExpenseOwed` is public/pure (named: amount, splitMode, splitDistribution,
  scope, customSplitParticipants, payerId, participantIds, …).
- `eventSettlementsProvider`→`watchSettlements` filters `isDeleted==false`; event settlement update/delete
  rules-denied (append-only) → soft-deleted EVENT settlement unreachable. **Drop soft-deleted-settlement
  display; corrections = append-only offsetting rows (delivered live).** `Settlement.groupSettleUpId` IS set
  on the per-event docs a #752 settle-up decomposes into (event subcollection) → `isGroupLinked` reachable;
  the residual GROUP settlement is intentionally out of an event receipt (`scope` column always `event`).
- Recap entry: `event_recap_screen.dart` (has `ref`+`EventRef`) → `showRecapShareSheet`; `_RecapShareSheet`
  is a plain `StatefulWidget` (no `WidgetRef`, no `groupId`; `EventRecap` has `eventId` only) → convert to
  `ConsumerStatefulWidget` + thread `EventRef`. **[G1.]**

### 1. `lib/features/activity/services/activity_service.dart` (extend) **[G1/G2]**

```
/// Loads ALL of one event's audit logs (capped) for the Trip Receipt. Single
/// `createdAt` DESC query (no composite index) so the cap keeps the MOST RECENT
/// corrections. Caller filters to category=='MONEY' && eventType in {UPDATE,DELETE}.
Future<({List<ActivityLog> logs, bool capHit, bool fromCacheEmpty})> fetchAllEventAuditLogs(
  EventRef ref, {int cap = 500});
```

`capHit = raw docs == cap` (raw count includes CREATEs — coverage stamp says so honestly).

cache-first `GetOptions` — **do not force `Source.server`** (breaks offline, per the file's own warning).

### 2. `lib/features/events/providers/trip_receipt_provider.dart` (new) **[G2]**

```
enum AuditCoverage { complete, capped, unverifiedOffline, unavailable } // [G3: split offline vs error]

// .autoDispose so a re-open re-fetches fresh corrections (the data sections are
// live streams; a non-autoDispose one-shot would freeze the audit at first fetch
// and a re-export would silently miss newer edits / keep a stale offline stamp).
// [G3 P2] NOTE: autoDispose is safe HERE (transient sheet-scoped providers); the
// #104 landmine forbids it only on the ledger/balance providers, which we READ.
final tripReceiptAuditProvider =
  FutureProvider.autoDispose.family<({List<ActivityLog> corrections, AuditCoverage coverage}), EventRef>((ref, r) async {
    try {
      final res = await service.fetchAllEventAuditLogs(r);
      final corr = res.logs.where((l) => l.category=='MONEY' && (l.isUpdate || l.isDelete)).toList();
      final cov = res.fromCacheEmpty ? AuditCoverage.unverifiedOffline
                : res.capHit ? AuditCoverage.capped : AuditCoverage.complete;
      return (corrections: corr, coverage: cov);
    } catch (_) {
      return (corrections: const <ActivityLog>[], coverage: AuditCoverage.unavailable); // [G3 P3: not "offline"]
    }
  });

final tripReceiptProvider = Provider.autoDispose.family<AsyncValue<TripReceipt>, EventRef>((ref, r) {
  final event   = ref.watch(eventDetailProvider(r));            // AsyncValue<Event?>
  final exp     = ref.watch(eventExpensesProvider(r));
  final setl    = ref.watch(eventSettlementsProvider(r));
  final members = ref.watch(groupMembersProvider(r.groupId));
  final audit   = ref.watch(tripReceiptAuditProvider(r));
  // AsyncLoading if any of {event, exp, setl, members, audit} isLoading OR event.value == null.
  // AsyncError if any of {event, exp, setl, members} hasError.
  // audit error/absent -> NON-fatal: corrections [], coverage unverifiedOffline.
  // else: final view = ref.watch(ledgerViewProvider(r));  // non-degenerate once event present
  //       AsyncData(buildTripReceipt(event: event.value!, view..., corrections, coverage, generatedAt));
});
```

Gating on `eventDetailProvider`+`members` (not just exp/setl/audit) closes both the #647/#648 false-empty
**and** the defensive-empty false-complete. CTA gates on `AsyncData`. `generatedAt` read at share time.

### 3. `lib/features/events/models/trip_receipt.dart` (new)

```
class TripReceipt {
  final String eventId, eventName; final EventType eventType;
  final DateTime? startDate, endDate; final bool isClosed; final DateTime? closedAt; final String? closedByName;
  final DateTime generatedAt;
  final List<String> participantNames;                 // serialized as a PARTICIPANTS section [G2]
  final List<ReceiptExpense> expenses;                 // current (isDeleted == false)
  final List<ReceiptAllocation> allocations;           // per-expense per-person owed (oracle universe)
  final List<ReceiptCorrection> corrections;           // audit UPDATE/DELETE
  final AuditCoverage correctionsCoverage;             // complete | capped | unverifiedOffline [G2]
  final List<ReceiptSettlement> settlements;           // live (append-only); group-linked flagged
  final Map<String, List<ReceiptNet>> netsByCurrency;  // oracle balances, verbatim
  final List<String> currencies; final bool isEmpty;
}
typedef ReceiptExpense    = ({ String id, DateTime date, String? description, String? categoryId,
                              String payerName, Decimal amount, String currency, String splitMode });
typedef ReceiptAllocation = ({ String expenseId, String personName, Decimal owed, String currency });
typedef ReceiptCorrection = ({ DateTime date, String kind /* EDIT|DELETE */, String expenseId,
                              String? description, String actorName, bool detailsCaptured,
                              Decimal amount, String currency,                       // [G2] always populated
                              ({Decimal before, Decimal after})? amountChange,
                              ({String before, String after})? descriptionChange,
                              ({String before, String after})? payerChange });        // name()-resolved [G2]
typedef ReceiptSettlement = ({ DateTime date, String fromName, String toName, Decimal amount,
                              String currency, bool isGroupLinked, String? note });
typedef ReceiptNet        = ({ String participantId, String personName, Decimal net });
```

### 4. `lib/features/events/utils/trip_receipt_builder.dart` (new)

Pure `TripReceipt buildTripReceipt({event, expenses, settlements, participants /* universe */, corrections,
coverage, balancesByCurrency, roster, generatedAt})`. Rules:

- **`name(id)`** **[G2 P3 — correct null-guard]**:
  `final raw = roster[id]; return raw == null ? <placeholder> : MemberNameResolver.stripDiscriminator(raw);`
  — never `roster[id]!`, never the raw id. Applied to **every** identity surface: payer, `payerChange`
  before/after, settlement parties, balance `personName`, `participantNames`, **and the correction
  `actorName`** (= `name(log.actorId)`, NOT `log.actorName ?? log.actorId` — the raw-UID fallback is
  forbidden). **[G3 P2]**
- **Same-name disambiguation [G3 P2]:** stripping the #196 ` (#last4uid)` discriminator can collapse two
  same-display-name members. After building `name()`s, a builder pass appends a **non-UID ordinal**
  (` (2)`, ` (3)`, stable by sorted `participantId`) to colliding names — distinct rows, zero UID bytes.
- Expenses: live → `ReceiptExpense` (raw `categoryId`; payer via `name`).
- Allocations: per live expense → `allocateExpenseOwed(participantIds: participants.map((p)=>p.id), …)`
  → one `ReceiptAllocation` per ower (`name`). **Drop any ower outside the balance universe
  (`participants`), mirroring the oracle's owed drop-guard** (`expense_provider.dart:315`), so ALLOCATIONS
  sum-reconciles with BALANCES across **all** split modes (non-equal splits divide over `splitDistribution`
  keys, which can name an out-of-universe key the oracle dropped). **[G2 P1 / G3 P2]**
- Corrections: per UPDATE/DELETE log, `ExpenseAuditDiff.fromMetadata` in **try/catch**. **`diff.after`
  present** → set `amount/currency` from it (= `diff.before` for a DELETE). `kind=DELETE` →
  `detailsCaptured:true` with the amount. `kind=EDIT` → fill amount/description/payer change tuples
  (`payerChange` `name()`-resolved); `hasFieldChange==false` → `detailsCaptured:false` generic "edited"
  row (still carries amount). **Throw OR `diff.after == null`** (legacy/empty `metadata:{}` — `tryParse`
  returns null without throwing) → `detailsCaptured:false` **"unreadable entry"** with `amount=Decimal.zero`,
  `currency=''` (sentinel; **excluded from per-currency aggregation**, shown as "—" in CSV). **[G3 P2]**
- Settlements: live only; `isGroupLinked = groupSettleUpId != null`; names `payerName/recipientName ?? name(id)`.
- Balances: copy `balancesByCurrency` → `netsByCurrency` (keep `participantId` **model-internal only — the
  CSV serializer NEVER emits it** [G3 P3]; `personName = name(id)`). No recompute.
- `participantNames`: `name(id)` over the universe. `currencies`: union, GCC-first; the `''` sentinel is
  never a currency. `isEmpty`: expenses+settlements+corrections empty.

## Verification principles (reported)

1. **Classify callsites**: all reads INBOUND/display-only; CSV is terminal output. **No OUTBOUND/write/schema/rules.**
   The one new path is a **read** (`fetchAllEventAuditLogs`).
2. **Verify claims vs code**: re-checked this session — no audit stream provider + 50/page; `ledgerViewProvider`
   shape/defensive-empty/`.participants` universe; `eventDetailProvider`/`groupMembersProvider` keys;
   `categoryNameForId` arity; `stripDiscriminator`; `allocateExpenseOwed` + universe; soft-delete leaves money
   unchanged; settlement append-only + `groupSettleUpId`; share sheet lacks ref/groupId.
3. **Trace read-path per write-path**: **no write-path.** New read = audit fetch → CORRECTIONS, coverage-stamped.
4. **Enumerate fields from types**: done.
5. **Data contracts**: exact model/typedefs, exact provider+service+builder+`shareCsv` signatures + universe
   threading + name() guard + sheet param.
6. **Arithmetic decomposition**: balances verbatim; allocations via canonical allocator over the **oracle
   universe** (reconciliation-tested); only new arithmetic = fils→Decimal + per-currency grouping.
7. **Adversarial orthogonal axis**: display/export fix exercised against settlements/money-flow + identity
   (#752 group-linked, append-only correction, #249 residual, multi-currency), the audit-truncation axis
   (>500 CREATE-dominated), and the soft-delete-amount-preservation axis.
