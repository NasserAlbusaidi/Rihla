- `docs/plans/2026-05-18-arabic-localization-pr2b-ledger-design.md`

## Goal

Land the Wave 0 foundation as a single atomic commit on branch `feat/l10n-pr2b-ledger`:

1. ~130 new ARB key pairs added to both `lib/l10n/app_en.arb` and `lib/l10n/app_ar.arb`. CI completeness lint passes.
2. Two new helpers created with TDD-first unit tests: `lib/core/utils/expense_scope_display_name.dart` and `lib/features/ledger/utils/localized_category_name.dart`.
3. Two minimal API changes (signature only, no behaviour change) to existing utils: `ledgerCategoryName(int bucket)` gains `AppLocalizations l10n` param in `lib/features/ledger/utils/ledger_categories.dart`; `formatShortMonthDay(DateTime date)` gains `String localeTag` param in `lib/core/utils/formatters.dart` and delegates to `intl` `DateFormat.MMMd(localeTag)`.
4. Compile-fix patches at the existing callsites that consume those changed signatures: `lib/features/ledger/widgets/ledger_category_strip.dart:142` and `lib/features/ledger/widgets/expense_editor_body.dart:1215`, plus `lib/features/groups/widgets/settle_up_page_body.dart:466` `DateFormat('MMM d')` → `DateFormat.MMMd(localeTag)`.
5. All existing tests still pass. New unit tests for the helpers pass and assert Arabic-distinct-from-English (not just `isNotEmpty`).

Read **Wave 0 section** of the implementation plan (`docs/plans/2026-05-18-arabic-localization-pr2b-ledger.md`, look for "## Wave 0 — Foundation") for the full task-by-task breakdown including code skeletons.

## Constraints

These are the gate-anchored invariants — violations are spec-failure, not stylistic choices:

- **No money math changes.** Do NOT touch `lib/features/ledger/providers/expense_provider.dart` (contains `BalanceCalculator`), `lib/core/services/money_serializer.dart`, or `lib/shared/widgets/r_amount.dart`. The OMR-only 3dp bug at `r_amount.dart:84` is a deferred follow-up; leave it.
- **No bucket-logic changes.** `ledgerCategoryBucket(String? name)` in `ledger_categories.dart` keeps its body and signature UNCHANGED. Only `ledgerCategoryName` gets an `AppLocalizations` param. The substring-matching brokenness for Firestore expenses (which have `categoryName: null`) is deferred to follow-up #8.
- **No router/security/Functions changes.** Do NOT touch `lib/core/router/app_router.dart`, `security/firestore.rules`, anything under `functions/`, or `lib/firebase_options.dart`.
- **No UI translation in Wave 0.** Widgets get translated in Waves 1–7. Wave 0 lands ARB keys + helpers + minimal signature changes only. The widgets MUST still render English everywhere after Wave 0.
- **Flutter version pinned at `^3.10.1`**. Riverpod 2.x. `decimal` package for money (never `double`). gen-l10n ARB pipeline; do NOT introduce a different l10n library.
- **Dart conventions per project CLAUDE.md:** no hardcoded `Color(0xFF…)` outside theme tokens; no `Navigator.push` / `state.extra` for nav; no `context.goNamed` (path strings only). These don't apply to Wave 0 directly but if you find yourself near them, leave them alone.
- **No new comments in code unless WHY is non-obvious.** Identifier names should carry the WHAT.
- **Conventional commits**: `feat(l10n): PR2b/wave-0 — ARB keys, helpers, l10n-ready ledger_categories + formatters`. Single commit at the end. Do not amend prior commits.
