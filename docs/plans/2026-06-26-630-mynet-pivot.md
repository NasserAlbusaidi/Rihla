# #630 — pivot `myNetByCurrency` once per build (O(C×M²) → O(C×M))

**Date:** 2026-06-26
**Issue:** #630 perf(money): `myNetByCurrency` is O(C×M²) across member/roster lists — pivot once per build
**Labels:** P3, money, tech-debt, performance. **Gate-category** (money helper in `expense_provider.dart`).

## Problem (verified against live code, not the issue's stale line refs)

`myNetByCurrency(buckets, uid)` (`lib/features/ledger/providers/expense_provider.dart:903-914`) double-loops every currency bucket × every `UserBalance` in that bucket to extract one uid's nets — O(C×M) per call. Called **once per member/roster row**, each list is O(C×M²). Because `computeGroupBalances` fills each bucket with every uid, `balancesPerBucket == members`, so rosters are O(members² × currencies) per rebuild.

The issue's callsite line numbers predate #628/#629. **Live callsites (re-grepped 2026-06-26):**

Single-uid reads (one call, cheap — leave or derive from pivot):
- `ledger_perspective_provider.dart:85` — current user's `myLines`
- `event_command_center.dart:138` — current user's `myLines` (screen build)
- `group_detail_screen.dart:157` — current user's `balanceLines` (screen build)

Per-row loops (the O(C×M²) hot spots):
- `ledger_perspective_provider.dart:116` — roster loop over `othersByPid.values`
- `event_command_center.dart:1157` — `_RosterStrip` `ListView.separated` itemBuilder over `event.participantIds`
- `group_detail_screen.dart:1054` — `_MembersCard` `for` loop over `others`

> `ledger_screen.dart:217` (issue ref) is now `perspective.peopleCountByCurrency[...]` — NOT a `myNetByCurrency` call. The ledger screen's per-person pivots already moved into `ledgerPerspectiveProvider` (#628). No change there.

## Fix

Add a pure helper next to `myNetByCurrency`:

```dart
/// One single pass pivot of [buckets] → `participantId → {currency: net}`,
/// each inner map zero-filtered exactly like [myNetByCurrency]. For list
/// surfaces: build ONCE, then `pivot[uid] ?? const {}` per row is O(1),
/// collapsing the former O(C×M²) per-row pivots to O(C×M) for the whole list.
/// Equivalence contract: `pivot[uid]` == `myNetByCurrency(buckets, uid)` for
/// every uid present in [buckets].
Map<String, Map<String, Decimal>> pivotNetsByParticipant(
  Map<String, List<UserBalance>> buckets,
) {
  final pivot = <String, Map<String, Decimal>>{};
  for (final entry in buckets.entries) {
    for (final b in entry.value) {
      if (b.netBalance != Decimal.zero) {
        (pivot[b.participantId] ??= <String, Decimal>{})[entry.key] =
            b.netBalance;
      }
    }
  }
  return pivot;
}
```

Then at each per-row loop, build the pivot once before the loop and index it:

1. **`ledger_perspective_provider.dart`** — build `pivot` once; derive BOTH `myLines` (`pivot[currentPid] ?? const {}`) and each roster `otherLines` (`pivot[other.participantId] ?? const {}`) from it. Removes the existing `1 + M` separate passes.
2. **`event_command_center.dart` `_RosterStrip.build`** — build `pivot` once before the `ListView.separated`; itemBuilder reads `pivot[uid] ?? const {}`. (Screen-build `myLines` at :138 stays `myNetByCurrency` — single read, no list.)
3. **`group_detail_screen.dart` `_MembersCard` build** — build `pivot` once before the `for` loop; row reads `pivot[others[i].key] ?? const {}`. (Screen-build `balanceLines` at :157 stays `myNetByCurrency`.)

`myNetByCurrency` is RETAINED — it remains the right tool for the three single-uid screen-build reads (building a whole pivot to read one uid is wasteful) and is covered by existing tests.

## Behavioral contract (this is a pure refactor — output must be byte-identical)

For every uid: `nonZeroNetsGccFirst(pivot[uid] ?? const {})` == `nonZeroNetsGccFirst(myNetByCurrency(buckets, uid))`.

- Zero-filter: pivot drops `netBalance == Decimal.zero` exactly as `myNetByCurrency` does (EXACT `!= Decimal.zero`, no tolerance — keeps sub-0.001 residuals visible, #382 PR-5 contract).
- Absent uid: `myNetByCurrency` omits buckets where uid is absent; `pivot[uid]` only contains currencies where uid had a non-zero balance → identical.
- Null uid: `pivot[null]` returns null (Map `operator []` takes `Object?`) → `?? const {}` → empty, matching `myNetByCurrency(_, null) == const {}`.
- Key order: irrelevant — `nonZeroNetsGccFirst` re-sorts via `sortedGccFirst`.
- Duplicate uid in one bucket: cannot happen (one `UserBalance` per participant per bucket); if it did, last-wins in both paths.
