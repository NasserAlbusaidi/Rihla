# #485 — collapse the split editor into one Split card

**Milestone:** 1.7.0 · **Labels:** P3, tech-debt, design · **Gate:** exempt (IA/layout + copy only)
**Mockup (signed off):** `docs/design/mockups/485-split-card.html`
**Depends on:** #242 (real per-person figures) — already shipped/closed.

## Problem

The expense editor stacks one concept — *who fronted it, who it divides between, how* — across **three titled `_Section`s** (`Paid by` / `Split between` / `How`), each with its own sheet, and there are **two payer pickers** for one field: the good `_PayerPickerSheet` (#280, "Paid by → Change") and a buried stock-Material `DropdownButton` `_PayerSelector` inside the "Customise" sheet, which also writes `payerParticipantId`. Set the payer in one place and it disagrees with the other.

## Outcome (done = )

One **Split** card replaces the three sections, top-to-bottom:
1. **Paid by** — one inline row (avatar + name + "Change"), opens `_PayerPickerSheet`. The second payer picker is gone.
2. **Who splits** — scope segmented control, plain language: **Everyone** / **Some people** / **Just me**. "Some people" reveals the existing custom roster inline.
3. **How** — mode segmented control: **Equal / Shares / Exact / %**. Equal is inline; Shares/Exact/% open the existing `showCustomSplitSheet` (untouched) for weights.
4. **Per-person rows** — vertical list with the real `allocateExpenseOwed` figures (#242), payer marked, own row highlighted, with the kept summary (`{amount} each` for equal · `Amounts vary per person.` for non-equal).
5. **Reconciliation footer** — "✓ Adds up to {total}".

Category strip stays above; "Where" (event · date) stays as its own section below. No `BalanceCalculator` / rules / routing / schema change — the numbers and the weights sheet are reused verbatim.
