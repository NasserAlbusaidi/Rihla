# Event-vs-Group Settle CTA (deferred #721 item — last piece of epic #202) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Turn the recap screen's read-only outstanding-status into an actionable settle CTA that offers both event-level and group-level settlement paths, completing the final acceptance box of epic #202 (and the re-scoped #721).

**Architecture:** A single additive CTA section appended to the bottom of `EventRecapScreen._content` (NOT per-currency). It is display + navigation only — it reads the already-computed `EventRecap.isSettledByCurrency` map (INBOUND, the same map the read-only per-currency status cards already use, so they can never disagree) and pushes two routes that already exist. No money math, no writes, no rules, no schema. Navigation uses `context.push` with absolute path strings, identical to every existing settle-up callsite.

**Tech Stack:** Flutter, Riverpod, GoRouter 13, themed `FilledButton`/`OutlinedButton`, `flutter gen-l10n` (EN + AR), `HapticService`.

## Spec (Gate-relevant facts, verified against code 2026-06-30)

- **Routing surface → the Gate is MANDATORY** (Operating Contract). This is the only Gate category touched. NOT money math (`isSettledByCurrency` is read-only display), NOT rules, NOT schema/field-name.
- **Both target routes exist** (`lib/core/router/app_router.dart`):
  - Event-level: `'/group/:gid/event/:eid/ledger/settle-up'` → `SettleUpScreen(groupId, eventId, preSelectedMemberId?)` (router L357-369).
  - Group-level: `'/group/:gid/settle-up'` → `GroupSettleUpScreen(groupId, preSelectedMemberId?)` (router L260-270).
- **Recap route** `'/group/:gid/event/:eid/recap'` is nested under the event hub (router L400-405), so `canPop()` is always true and `context.push` adds the settle screen on top — back returns to recap. No back-guard change. No new route, no redirect change.
- **Established navigation pattern** (matched exactly): `context.push('/group/$groupId/event/$eventId/ledger/settle-up')` (`ledger_screen.dart:403`, `event_command_center.dart:207/270`) and `context.push('/group/$groupId/settle-up')` (`group_members_section.dart:213`). Path strings only — NO `goNamed`, NO `extra`.
- **Screen already holds `groupId` + `eventId`** as constructor fields (`event_recap_screen.dart:38-39`) — path building is trivial.
- **Closed-event behaviour:** recap is primarily the closeout for CLOSED events; settlements stay LIVE after close (#723/#766). Settling from a closed-event recap is exactly intended — so the CTA shows regardless of `event.isClosed`. It also shows on an open-event on-demand recap. Gate-relevant: the CTA must NOT depend on closed state.
- **Visibility predicate:** `anyOutstanding = currencies.any((ccy) => !(recap.isSettledByCurrency[ccy] ?? true))`, where `currencies` is the same `sortedGccFirst({...participantNetsByCurrency.keys, ...totalSpentByCurrency.keys})` set already built in `_content` (L149-152). If every currency is settled → no CTA (the green "Everyone's settled up" status cards stand alone). `_content` is only reached on the non-empty path (`recap.isEmpty` → `_empty`), so `currencies` is never empty here.

### Verification principles run (reported out loud per Operating Contract)

1. **Callsite classification:** every value the CTA reads (`isSettledByCurrency`, `groupId`, `eventId`) is **INBOUND (display/navigation only)** — none feeds a write. The CTA persists nothing. ✅
2. **Concrete claims verified against code, not memory:** route paths (`grep` in `app_router.dart`), nav pattern (`grep` of existing `context.push` callsites), screen fields (Read L31-39), `isSettledByCurrency` field (Read `event_recap.dart` L91, L316 usage). ✅
3. **Read-path per write-path:** there is NO write-path (navigation only). The two routes are read by their existing screens, unchanged. ✅
4. **Fields enumerated from the type:** `EventRecap` exposes `isSettledByCurrency` (`Map<String,bool>`), `participantNetsByCurrency`, `totalSpentByCurrency` (Read `event_recap.dart` L95-113). The CTA reads only `isSettledByCurrency`. ✅
5. **Data contract:** navigation contract is two literal path strings + `HapticService.lightClick()` first. No callback signatures, no map keys. ✅
6. **Arithmetic decomposition:** N/A — no aggregate math added. The CTA's visibility OR-folds per-currency booleans (`any`), not money. ✅
7. **Adversarial pass on an orthogonal axis (settlements):** the recap can be SETTLEMENT-ONLY in a currency (no expense). `isSettledByCurrency` is keyed off the BALANCE pass (folds settlements), and the `currencies` set unions `participantNetsByCurrency.keys` (balance currencies), so a settlement-only outstanding currency is covered by `anyOutstanding`. Also: a fully-settled multi-currency event → `anyOutstanding == false` → no CTA. Also: a square-but-active user (net 0) on an event where OTHERS are outstanding → CTA still shows (settle-on-behalf #595 is allowed; visibility is per-event, not per-user). ✅

```dart
  /// Actionable event-vs-group settle CTA (#721 deferred item). Shown once
  /// (NOT per-currency) when ANY currency is outstanding. Navigation + display
  /// only — reads the already-computed isSettledByCurrency map, persists
  /// nothing. Both routes already exist; pushed with absolute path strings
  /// (the established convention), back returns to the recap.
  List<Widget> _settleCtaSection(
    BuildContext context,
    EventRecap recap,
    List<String> currencies,
  ) {
    final anyOutstanding =
        currencies.any((ccy) => !(recap.isSettledByCurrency[ccy] ?? true));
    if (!anyOutstanding) return const [];
    final c = context.colors;
    return [
      SizedBox(height: context.spacing.space24),
      Container(
        key: EventKeys.recapSettleCta,
        width: double.infinity,
        padding: EdgeInsetsDirectional.all(context.spacing.space20),
        decoration: BoxDecoration(
          color: c.cardSurface,
          borderRadius: BorderRadius.circular(context.spacing.radiusCard),
          boxShadow: context.shadows.raised,
        ),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          mainAxisSize: MainAxisSize.min,
          children: [
            Text(context.l10n.recapSettleCtaTitle,
                style: TextStyle(
                    fontSize: 16,
                    fontWeight: FontWeight.w700,
                    color: c.textPrimary)),
            SizedBox(height: context.spacing.space4),
            Text(context.l10n.recapSettleCtaBody,
                style: TextStyle(fontSize: 13, color: c.textSecondary)),
            SizedBox(height: context.spacing.space16),
            FilledButton(
              key: EventKeys.recapSettleEventButton,
              onPressed: () {
                HapticService.lightClick();
                GoRouter.of(context)
                    .push('/group/$groupId/event/$eventId/ledger/settle-up');
              },
              child: Text(context.l10n.recapSettleThisEvent),
            ),
            SizedBox(height: context.spacing.space8),
            OutlinedButton(
              key: EventKeys.recapSettleGroupButton,
              onPressed: () {
                HapticService.lightClick();
                GoRouter.of(context).push('/group/$groupId/settle-up');
              },
              child: Text(context.l10n.recapSettleAtGroup),
            ),
          ],
        ),
      ),
    ];
  }
```
> Buttons are full-width because the column is `crossAxisAlignment: stretch`. Styling is 100% themed (`filledButtonTheme`/`outlinedButtonTheme`); no hardcoded `Color(0xFF…)`, no `textMuted` read → theme purity clean.
