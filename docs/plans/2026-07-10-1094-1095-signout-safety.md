# #1094/#1095 Sign-out safety implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent durable-account sign-out from silently deleting queued offline writes, and remove the outgoing UID's FCM token before the authorized UID changes.

**Architecture:** Treat `waitForPendingWrites` as a preflight before the irreversible cache-isolation window. A timeout throws a typed exception while the current session remains intact; the Profile UI offers a second, explicit discard confirmation whose retry is the only path that skips the preflight. Once sign-out is approved, remove the outgoing UID's FCM token, engage isolation, mark persistence dirty, sign out, write the outcome marker, and restart in the existing order.

**Tech Stack:** Flutter, Dart, Riverpod 2.x, Firebase Auth, Cloud Firestore, Mocktail, Flutter widget tests, ARB localization.

## Global Constraints

- Implement #1094 before #1095 and commit them separately.
- Write and run a failing regression test before each production change; preserve the exact RED output for the PR body.
- Preserve #213: never recover a token-check failure by calling `signOut` and `signInAnonymously`.
- Preserve the durable-user guard; anonymous users cannot sign out.
- Keep the pending-write abort outside cache isolation. `CacheIsolationController` has no in-process release path.
- Keep `markFirestorePersistenceDirty` awaited before `_auth.signOut()` on every actual sign-out.
- Keep the guaranteed restart for every failure after isolation starts.
- Do not change `security/firestore.rules`, `functions/**`, or `**/models/**.dart`.
- Do not add a custom sync queue, schema field, Firestore key, or persistence write.
- Use localized EN/AR copy. Existing confirmation copy must say synced data stays in the cloud.
- Run `bash tool/check_theme_purity.sh` because `profile_screen.dart` and a widget file change.
- The final commit body must contain both `Closes #1094` and `Closes #1095`.

    firestore.waitForPendingWrites,
