Build contract

The card is a pure StatelessWidget (RecapShareCard) that takes plain data — no Riverpod, no Firestore. It reads context.colors/spacing/l10n like any screen because it renders in the live tree (the preview sheet), so fonts/theme/Directionality are already in scope. Every money value is INBOUND display from already-correct EventRecap output; nothing here feeds a write.

Element → data map (hero currency = group currency, GCC-first fallback)

Cover band artCoverPalette.forEventType(event.type) — the same procedural CoverArt as the hub.
CaptionRihla · Wrapped + · {MON YYYY} from startDate ?? endDate (omit if both null).
Titlerecap.eventName (serif italic, 1 line, ellipsis).
SubstartDate–endDate range + nights; omit if no dates.
Hero totalrecap.totalSpentByCurrency[hero] via RAmount.
Multi noteother currencies in totalSpentByCurrency (GCC-first), + {amt} · {amt}; never cross-summed.
Stat · Peoplerecap.participantCount (live roster).
Stat · Expensesrecap.expenseCount.
Stat 3 · Avg/dayheroTotal ÷ inclusiveDays when both dates exist; else Per person = heroTotal ÷ participantCount. Display-only Decimal division, currency-rounded for render — never persisted.
Top spenderrecap.payerTotalsByCurrency[hero].first → name via roster.
Biggest splurgerecap.biggestExpenseByCurrency[hero] → description, else category name.
Where it wentrecap.categoryTotalsByCurrency[hero] — top 3, remainder folded into "Other"; colors via categoryColorForId.
Status pillrecap.isSettledByCurrency[hero] → "All settled" (sage) / "{k} still to settle" (saffron, k = debtors in hero ccy).
Brand"Rihla" wordmark (Instrument Serif italic) + saffron dot.

Degradation (the card never throws)

  • No expenses → recap isEmpty; the Share action is hidden (nothing to wrap).
  • No dates → drop caption month + sub line; stat 3 becomes Per person.
  • 0–1 categories → bar collapses to a single segment; ≤4 legend chips max.
  • Long names → 1-line ellipsis (title, payer, biggest).
  • Multi-currency → only the hero block's breakdown shows; note carries the rest.

Plumbing

  • Entry: a share icon in the recap screen header (top row, end side) → showModalBottomSheet preview (no router/deep-link surface).
  • Preview: the card at fixed 360×450 inside a FittedBox (scales to fit), wrapped in RepaintBoundary; a "Share image" CTA + close.
  • Capture: boundary.toImage(pixelRatio: 3) → PNG bytes (awaits a frame if debugNeedsPaint).
  • Share: new shareImage(context, bytes, fileName:'rihla_recap.png', text:…) in share_helper.dart → Share.shareXFiles([XFile.fromData(bytes, mimeType:'image/png')], fileNameOverrides:['rihla_recap.png'], sharePositionOrigin: _shareOrigin(context)). share_plus 10.1.4 writes the in-memory bytes to a temp file itself — no path_provider.
