Activity UI · consistency pass

The three activity feeds (per-event, per-group, cross-group tab) + home “Recently” share data but not chrome. This extends the signed #490 row unification with the screen-level fixes found in the 2026-07-04 review: the per-event feed’s visual monotony, the per-group screen’s off-brand top bar and legacy radius, day-header and footer drift, screen-background depth (grain parity + wash + cover-blend options), and a small polish punch list. Deliberate splits are kept: flat card on the inert per-event feed (#866) vs raised on the tappable feeds (#807); ink-filled active pills (app-wide convention, ledger strip). ← gallery

1

Per-event feed — every row is the same orange tile

activity_feed_screen.dart · _CategoryIcon + ExpenseAuditDetail

The event feed’s categories are MONEY/GEAR/DOCS — but GEAR and DOCS died with Phase 39, so in practice every non-delete row renders the identical saffron banknote tile: an “added” and an “edited” are indistinguishable at a glance. Amounts exist but are buried in the 12px audit summary line under the verb, not in the trailing scan column every other money row in the app uses. The group feed already solved both (#808’s receipt vocabulary + trailing RAmount) — adopt it here.

Proposal: map eventType → per-action glyph (add = saffron receipt+ · edit = neutral pencil · delete = muted receipt−), move the amount to the trailing column, drop the now-redundant CREATE summary line, add the wireframe day-date. Flat card stays (#866).

Screen background — the feeds are flat paper, and inconsistently so

GrainOverlay parity + optional depth · all three routed activity screens

Found while chasing this: the Activity tab already renders under the shell’s 3.5% paper-grain (BottomNavShell wraps all tabs in GrainOverlay), but the routed entries — /activity, the group timeline, the per-event feed — are bare scaffoldBackground. The same screen has texture as a tab and none via deep-link. Beyond parity, the flat paper is what makes these screens feel blank next to Home’s hero. Three treatments, cheapest to richest:
