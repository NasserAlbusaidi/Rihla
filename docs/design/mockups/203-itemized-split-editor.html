#203 · S2

The itemized editor — list the bill, tap who had each, app computes the exact split

P2 · money · the Gate applies (schema write + read-path + money math)

Scenario: Coffee run, Nasser paid OMR 6.100. Shared pastries for the table, then each had a different drink. Today the payer opens How → Exact and types four hand-computed amounts. With Itemized they list the items, assign each (a one-tap Everyone = the shared base), and the app derives the exact splitDistribution — persisted as a normal SplitMode.exact + splitExplanation, so balances and the server oracle are untouched. Hessa, who only shared the pastries, owes OMR 0.300 — not 0.

Scope: item rows · shared-base via "Everyone" · live reconcile-to-total · reopen read-back. Deferred → #605: service / tax / tip / discount. No new SplitMode — Itemized is a 5th option in the How sheet that produces an exact split.
