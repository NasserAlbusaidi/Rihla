#361 · Cold-start white-flash

On a cold launch the native OS window paints launch_background.xml — the stock Flutter plain white — for a beat before the first Dart frame draws the paper-tinted SplashScreen (the saffron R tile + Rihla wordmark). The result is a jarring white flash that breaks the brand the instant the app opens. The fix swaps the launch drawable to the scaffold #F6F1E6 paper + a centered mark so native→Flutter is one continuous frame. Both light and dark modes need a matching values-night entry. ← gallery
