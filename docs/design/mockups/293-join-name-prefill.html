#293 · Join screen — name bleed & mistype lockout

Two rough edges on join_group_screen.dart. (1) Your name silently seeds from the device-wide deviceName — a nickname from a friends group leaks into a family ledger. (2) The code field auto-submits on the 6th char (if (value.length == 6) _joinGroup()), so a hand-relayed code mistyped a few times fires fast failures that burn the 5/hr lockout in joinGroupByInviteCode.ts. Both variants keep the real layout (mood header → name → code → hint → CTA); they differ on the name field and how the code commits. ← gallery

#293

polish(join): name pre-fills from cross-group device name; mistyped codes burn the 5/hr limit

P3 · design · join_group_screen.dart + joinGroupByInviteCode.ts

The fix is two-part and the same in both: kill the auto-submit on the 6th character (manual Join group button only) and add a typo-tolerant note reminding the user the code never contains O / 0 / I / 1. The fork is only the name field — blank with a one-tap "use my usual name" chip vs. pre-filled but explicitly confirmed for this group.

Recommendation: Variant V1 (Blank + hint) — a blank field can't silently leak the wrong persona; the chip keeps the common case one tap, and removing auto-submit stops the lockout burn.
