#490

tech-debt(ui): one shared ActivityRow for every feed

P3 · tech-debt · design · the row half (avatars #506, headers #507 shipped)

The feeds render the same events, so the body (bold actor + grey verb phrase) is already identical everywhere. What diverged is the chrome and the trailing meta. The proposal: one ActivityRow with a single leading treatment and a small set of optional slots the caller fills per feed — so the differences that are real (a group tag only makes sense across groups; an amount only on money rows; an audit diff only on edits) stay, but they stop being four separate widgets.

Recommendation: category-icon as the canonical leading (it answers what happened — the point of an activity feed — and three of four feeds already use it; the actor’s name is already in the text). Home “Recently” adopts it, dropping the avatar outlier. Slots: group tag amount settlement sign audit diff.
