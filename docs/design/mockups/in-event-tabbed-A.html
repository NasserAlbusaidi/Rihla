The three tabs

Expenses — the ledger is the home view (default tab): grouped by day, category icon, payer, split note, amount. Search/filter lives here. This replaces the separate Ledger screen.

Settle up — the optimized who-pays-whom plan, not a passive list. Each row = one real transfer with its action: Mark received when you’re owed, Mark paid → let them know when you owe (the WhatsApp notify from #367). “3 payments clear the trip” is the simplify-debts framing.

Activity — the timeline / audit feed: adds, edits (#248 diff), settlements, joins.

No Gate — UI re-layout; routes stay for deep links

Header behavior

Balance is pinned on top; scroll the Expenses list and it collapses into the title row (the small OMR 12.300 appears beside the name), handing the list its space back.

What it costs

Keep /ledger, /activity, and the settle route alive (deep links still work); the event screen embeds those same widgets as tab panels. The tabbing is presentation, so no money / route / schema surface changes. Pairs cleanly with #245’s group→event collapse.
