#203 · Itemized split helper

One person pays the whole coffee order, but everyone had a different drink. Today the editor's How sheet only offers Equally / Shares / Exact / Percent — so the payer has to do the per-person math by hand and type it into Exact. This adds an Itemized mode that lets you list the line items, tap who had each, and lets the app compute the exact splitDistribution — saved as a normal SplitMode.exact with itemized explanation metadata so balances are unchanged. ← gallery

#203

money/ux: add itemized split helper for items, shared items, fees & discounts

P2 · money · design · cluster:settlement-ux

All three are the new Itemized destination behind the editor's How → Customise action (the sheet that today shows the Equally/Shares/Exact/Percent segmented control). They differ on the input metaphor: drive from the items (V1), drive from the people (V2), or read like the paper bill (V3 — read-back/reopen view). All compute the same exact distribution — Americano 1.600 → Nasser, Espresso 1.200 → Sara, Latte 2.100 → Khalid, Hessa 0.000 (nothing ordered) — and persist splitExplanation for reopen/audit. Live reconcile-to-total before Save is mandatory (acceptance criteria). AC also requires a shared-base plus extras shortcut — shown in V2's secondary tab.

Recommendation: V1 (Item rows) — the bill is a list of items, assignee chips make "who had this" one tap, and the pinned per-person footer is the live reconcile-to-total the acceptance criteria require. Closest to the existing exact-split sheet, so the smallest build.
