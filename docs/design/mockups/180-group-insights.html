A read-only, per-currency Insights section at the bottom of the group screen: total spent, the highest-spending event, who fronted the most, whose share was biggest, and spend by category. Derived live from data the screen already streams — zero new listeners, nothing persisted.

Rules of the section
  • Header lives inside the widget — empty group ⇒ nothing renders, no dangling header (Gate R1 P2).
  • Category rows reuse the catalog's icon/colour tokens (cat1–cat6) — mockup hues are placeholders.
  • Names come from the #196-disambiguated memberNames map (departed payers render with the former-member suffix).
  • Amounts via RAmount; rows use directional start/end APIs (RTL mirrors).
  • Read-only: no taps, no navigation, no write path.
