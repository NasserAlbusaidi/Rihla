#354 · Invite straight to WhatsApp

WhatsApp is the dominant invite channel for the GCC launch market. Today the group invite button fires the generic OS share sheet via shareText(groupShareInviteMessage). This issue adds an optional WhatsApp-direct path that opens wa.me/?text=… prefilled with the same message — reusing AppLinks.inviteUrl (rihla-safar.web.app/join/<code>, never rihla.app) — and falls back to the OS share sheet when WhatsApp isn't installed. ← gallery

Recommendation: Variant V1 (dedicated button) — one tap from the group header straight into the channel people actually use, with the generic share kept beside it.
