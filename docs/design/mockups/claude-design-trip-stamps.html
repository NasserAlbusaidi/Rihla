05 / Decisions & open questions

The thinking

The symbol set

Twelve covers the real reasons groups form in Rihla — trips (tent, mountain, palm, sun, wave, compass, anchor), shared life (house, dining, coffee), and moments (gift, camera). Chosen for distinct silhouettes at 40px, not literal completeness.

Empty & selected states

No symbol → the serif monogram of the name's first letter (today's behaviour, now intentional). Selected is always a saffron ring + tint over the unchanged glyph; we never recolour the symbol to show selection, so ink stays meaningful.

RTL safety

The app ships Arabic, so nothing points: no bare arrows, no left/right asymmetry. Compass is a 4-point rose, the anchor and tent are mirror-symmetric, fork+knife reads as a balanced pair. The grid never flips meaning.

Ink = the six journal colours

Ink reuses the existing avatar palette — terracotta, harbour, ochre, olive, plum, slate — so groups and people draw from one harmonious set. Saffron stays reserved for actions and the selected ring; it is never an ink.

Could this extend to per-event tiles?

Yes, and cleanly. An event (a dinner, a fuel stop, a hotel) inherits its group's ink and picks a symbol from the same family — the dining glyph for a meal, anchor for a boat day — so a ledger reads as a strip of small stamps in one trip's colour. Same component, same picker, narrower symbol subset. Worth prototyping once the group rollout lands.
