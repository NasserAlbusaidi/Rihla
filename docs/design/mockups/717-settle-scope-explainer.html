#717 · Event-level settle-up scope explainer

Settlements carry scope: 'event' | 'group'. A group-scoped settlement clears someone's whole-group net across every event — but each event's own ledger keeps showing the full owe (the per-event drill-down is participantIds-only by design). Nothing on either settle surface says so, so a user can't tell what a payment covered. This adds a calm, persistent scope note pinned at the top of the shared SettleUpPageBody, with copy that differs by which surface you're on. Display-only — no balance math, no rules, no schema (gate-exempt). The confirm-sheet / persisted-snapshot half lives in the gated sibling #718. ← gallery
