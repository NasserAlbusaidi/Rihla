Rihla · design mockups

One HTML file per design-labelled issue, each with 2–3 phone-frame variants (or a before/after treatment for mechanical fixes), styled on the live rihla.css token contract — the same saffron / paper / ink, Geist · Geist Mono · Instrument Serif, and component vocabulary as the app. Open each, pick a direction, and the choice gets posted to its GitHub issue so the design is locked before any code. Every mockup already marks one variant ★ recommended — that's the default if you don't want to deliberate.
