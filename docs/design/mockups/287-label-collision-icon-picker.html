#287

design(polish): "Equally"/"Equal" label collision + decorative glyph row looks selectable

P3 · design · two batched fixes

The label collision has one correct answer — disambiguate the words so the WHO axis and the HOW axis never read as the same thing — so both variants ship the same copy fix. The real fork is the glyph row: V1 honours the affordance it already paints (wire the picker so a tap actually sets a group glyph), while V2 retreats — strips the selectable styling so the row is plainly decorative. Each phone shows both fixes together so the direction is picked as one coherent first-run feel.

Recommendation: V1 — Real picker. A bordered, evenly-spaced row of tappable tiles is the universal "pick one" pattern; users already try to tap it. Removing the border is the cheaper fix but teaches the user nothing and wastes a chance to give each group an identity on the home grid.
