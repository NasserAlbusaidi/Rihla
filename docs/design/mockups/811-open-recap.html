Decision & build notes

  • Pick P1 (recap banner) unless a persistent bar reads as too heavy on a live trip → then P2.
  • Remove the header cup RIconButton (event_command_center.dart:422-428) — safe, no test references recapButton/recapButtonTooltip.
  • Copy: reuse eventViewReceipt = "View recap" / "عرض الملخّص" for the action. P1's lead ("See the trip so far") needs one new EN+AR key; P2 needs none.
  • Visibility unchanged: show only when !event.isClosed && expenses.isNotEmpty. Closed events keep the Recap tab — never both.
  • Not Gate-category: route /group/:gid/event/:eid/recap already exists; no money / rules / schema surface. Standard TDD.
  • Tests (RED first): visible "View recap" text on open+expenses; tap routes to recap; hidden on 0 expenses; closed still uses the tab; narrow + RTL no RenderFlex overflow.
