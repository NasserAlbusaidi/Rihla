#841 — Arabic type stack

The mono-caption and italic-display treatments are Latin-only by construction: Geist Mono and Instrument Serif carry no Arabic glyphs, so Arabic falls back to the system face while inheriting letterSpacing 1.2–2.0 and FontStyle.italic. Letter-spacing visually disconnects joined Arabic letters (rendered live below — this page uses the same CSS the engine applies); synthetic italic slants a script that is never italicized. Money amounts are unaffected (Western digits render fine in Geist Mono). Approved direction: per-script token fix, sign-off on this gallery before code.

2 · Display italic (screen titles, hero numerals' labels)

AppTypography.display() defaults italic: true. Arabic through it gets a synthetic slant (no italic exists in the face or the script). The dedicated arabicDisplay() (Reem Kufi) is wordmark-only by design (#636) — not the fix vehicle.

Implementation options

Option B — semantic split (recommended). New AppTypography.caption(locale/context, …) for text captions: Latin → the exact current mono recipe; Arabic → sans-fallback w700, spacing 0, no uppercase transform. mono() is re-documented as numerals-only (amounts/dates/codes) and its text-caption call sites (~a dozen of the 75) migrate to caption(). display() gains a locale guard: under AR → upright + w500 (no synthetic italic). Mechanical, testable (goldens optional), no new fonts bundled.
Option A — locale branch inside the existing helpers. mono()/display() take the ambient locale and branch internally. Smaller diff (no call-site migration) but muddies the token contract: "mono" would silently not be mono in AR, and amounts routed through mono() must NOT branch — so the helper needs a "this is a number" flag anyway, which is Option B wearing a worse name.
Option C — bundle an Arabic caption face (e.g. IBM Plex Sans Arabic). Best visual control, +~100-300 KB app size, font-licensing/pipeline work. Defer to the 2.0 design pass unless the system-face result above reads as insufficient.

RECOMMENDATION: Option B now; revisit Option C at the 2.0 dark/design round. Sign-off on this page approves Option B's three rules: AR captions = sans w700/11px/spacing 0, AR display = upright w500, numerals stay Geist Mono everywhere.
