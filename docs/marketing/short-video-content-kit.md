# Rihla Short-Video Content Kit

Date: 2026-06-27

Goal: turn warm awareness into Android alpha installs from real groups.

Use these videos for Instagram Reels, TikTok, WhatsApp Status, and direct DM
follow-ups. Keep each video 8-15 seconds. Use real screen recordings when
possible. The CTA is not "try my app"; it is "use Rihla for one real shared
bill."

Replace `XX` with `01` through `10`.

## Recording Rules

- Record on Android.
- Use a real but harmless demo group name.
- Blur personal names, phone numbers, and WhatsApp chats.
- Show one clear action per clip.
- End with the next action: alpha access, install, create group, or add one real
  expense.
- Do not promise public availability while the app is still on closed alpha.

champion outreach beats passive content.
