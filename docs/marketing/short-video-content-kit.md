# Rihla Short-Video Content Kit

Date: 2026-06-27

Goal: turn warm awareness into Android installs from real groups.

Use these videos for Instagram Reels, TikTok, WhatsApp Status, and direct DM
follow-ups. Keep each video 8-15 seconds. Use real screen recordings when
possible. The CTA is not "try my app"; it is "use Rihla for one real shared
bill."

## Trackable Links

Use one link per post so the source stays readable.

| Use | Link |
|---|---|
| English install | `https://rihla-safar.web.app/?utm_source=instagram&utm_medium=video&utm_campaign=first_100&utm_content=video_XX` |
| Arabic install | `https://rihla-safar.web.app/ar?utm_source=instagram&utm_medium=video&utm_campaign=first_100_ar&utm_content=video_XX` |
| Oman use case | `https://rihla-safar.web.app/split-bills-oman?utm_source=instagram&utm_medium=video&utm_campaign=first_100_oman&utm_content=video_XX` |

Replace `XX` with `01` through `10`.

## Recording Rules

- Record on Android.
- Use a real but harmless demo group name.
- Blur personal names, phone numbers, and WhatsApp chats.
- Show one clear action per clip.
- End with the next action: install, create group, or add one real expense.
- Send champions a tracked install link; they install straight from Google Play.
