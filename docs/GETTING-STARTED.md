# Getting Started

How to go from a fresh clone to a running Rihla app.

---

## 1. Prerequisites

| Tool | Minimum | Notes |
|------|---------|-------|
| Flutter SDK | Dart ^3.10.1 (stable channel) | Run `flutter doctor` after install |
| Xcode | 15+ | iOS builds only. Required for Simulator and device signing. |
| Android Studio | Giraffe (2022.3) or later | For Android emulators and SDK tooling |
| CocoaPods | Any recent version | iOS dependency manager. `sudo gem install cocoapods` |
| Firebase CLI | Latest | Required only if you need to regenerate `firebase_options.dart` |

Verify your Flutter install:

```bash
flutter doctor -v
```

All checkmarks are not required for development, but Flutter, Dart, and at least one platform (Android or iOS) must be healthy.

## 2. Clone and Install

```bash
git clone <repo-url>
cd rihla

flutter pub get
```

`flutter pub get` also triggers CocoaPods resolution on macOS. If the iOS pod install fails at this step, see [Common Issues](#7-common-issues).

## 3. Firebase Setup

Firebase powers auth, Firestore, Storage, and push notifications. Three artifacts are required — two are gitignored and must be obtained from the Firebase Console, one is already committed.

### 3a. google-services.json (Android)

**Path**: `android/app/google-services.json`
**Firebase project**: `rihla-safar`
**Android package**: `com.safar.safar`

1. Open [Firebase Console](https://console.firebase.google.com/project/rihla-safar/settings/general)
2. Under **Your apps**, select the Android app (`com.safar.safar`)
3. Click **Download google-services.json**
4. Place the file at `android/app/google-services.json`

Without this file the Android build fails immediately.

### 3b. GoogleService-Info.plist (iOS)

**Path**: `ios/Runner/GoogleService-Info.plist`
**Firebase project**: `rihla-safar`
**iOS bundle ID**: `com.safar.safar`

1. Open [Firebase Console](https://console.firebase.google.com/project/rihla-safar/settings/general)
2. Under **Your apps**, select the iOS app (`com.safar.safar`)
3. Click **Download GoogleService-Info.plist**
4. Place the file at `ios/Runner/GoogleService-Info.plist`

Without this file the iOS app crashes on launch.

### 3c. firebase_options.dart

`lib/firebase_options.dart` is already committed to the repository — no action needed. It was generated by `flutterfire configure` and contains the `DefaultFirebaseOptions` for both Android and iOS (Firebase project `rihla-safar`).

If the Firebase project ever changes, regenerate it:

```bash
flutterfire configure
```

## 4. Configuration

The app requires a `config.json` file at the project root. This file is gitignored and must be created manually.

### Minimum config.json for local development

```json
{
  "SENTRY_DSN": "",
  "THAWANI_API_KEY": "",
  "THAWANI_PUBLISHABLE_KEY": "",
  "THAWANI_MODE": "test"
}
```

Empty strings are valid for local development. Sentry will not report errors and Thawani payment flows will fail, but all other features work normally.

See [docs/CONFIGURATION.md](./CONFIGURATION.md) for the full list of keys, what each one does, and production configuration.

## 5. Running the App

The `--dart-define-from-file` flag is required on every run. The app will start without it, but `SENTRY_DSN` and Thawani keys will fall through to their empty defaults, and the config is considered incomplete.

```bash
flutter run --dart-define-from-file=config.json
```

### Selecting a specific device

List connected and available devices:

```bash
flutter devices
```

Run on a specific device using its device ID:

```bash
flutter run -d emulator-5554 --dart-define-from-file=config.json   # Android emulator
flutter run -d iPhone\ 16     --dart-define-from-file=config.json   # iOS simulator
```

### App bootstrap order

On launch, `main()` initializes in this sequence inside `SentryFlutter.init`:

1. **Firebase** — `FirebaseConfig.initialize()` sets up Firestore offline persistence
2. **Anonymous auth** — `FirebaseConfig.ensureAnonymousSession()` restores or creates a session
3. **SharedPreferences** — loaded and injected into the Riverpod scope
4. **`runApp`** — `SafarApp` mounts

There is no login screen. A Firebase anonymous UID is assigned silently on first launch and persisted across restarts.

## 6. Running Tests

```bash
# All tests
flutter test

# Unit tests only
flutter test test/unit/

# A specific file
flutter test test/unit/balance_calculations_test.dart

# Integration tests
flutter test test/integration/

# Feature/widget tests
flutter test test/features/

# Static analysis
flutter analyze
```

### Test layout

| Directory | What's covered |
|-----------|---------------|
| `test/unit/` | Pure logic — BalanceCalculator, formatters, services, providers, models |
| `test/features/` | Widget tests for screens — groups, events, ledger, gear, logistics, vault, memories |
| `test/integration/` | Happy path, offline scenarios, Firebase auth, money round-trips |

Tests use `mocktail` for mocking, `fake_cloud_firestore` and `firebase_auth_mocks` to avoid real Firebase calls. Provider overrides replace `sharedPreferencesProvider` and other async dependencies in test scope — no real device or network is required.

## 7. Common Issues

### CocoaPods install fails after `flutter pub get`

```
Error: CocoaPods not installed or not in PATH
```

Install CocoaPods and retry:

```bash
sudo gem install cocoapods
cd ios && pod install
```

If `pod install` complains about a missing `Generated.xcconfig`:

```bash
flutter pub get   # generates Flutter/Generated.xcconfig
cd ios && pod install
```

### Firebase config file missing (Android build fails)

```
File google-services.json is missing.
```

Follow [Section 3a](#3a-google-servicesjson-android) to download and place the file. The file must be at `android/app/google-services.json` — not inside `android/` or the project root.

### Firebase config file missing (iOS app crashes on launch)

```
FirebaseApp: configure() was never called
```

Follow [Section 3b](#3b-googleservice-infoplist-ios) to download and place `GoogleService-Info.plist` at `ios/Runner/GoogleService-Info.plist`. Then do a clean build:

```bash
flutter clean
flutter pub get
flutter run --dart-define-from-file=config.json
```

### config.json missing (dart-define keys are empty)

```
FileSystemException: Cannot open file, path = 'config.json'
```

Create `config.json` at the project root using the template from [Section 4](#4-configuration). The file must be at the root (same level as `pubspec.yaml`), not inside `lib/` or `android/`.

### Dart SDK version mismatch

```
The current Dart SDK version is X.Y.Z.
Because rihla requires SDK version ^3.10.1, version solving failed.
```

Switch Flutter to the stable channel and upgrade:

```bash
flutter channel stable
flutter upgrade
```

### Pod version conflicts after updating Flutter

```
[!] CocoaPods could not find compatible versions for pod "..."
```

Delete the lock file and reinstall:

```bash
cd ios
rm Podfile.lock
pod install --repo-update
```
