# Quick Task 260415-g20: Fix memory photos never displaying

**Date:** 2026-04-15
**Status:** Complete

## Problem

Memory photos always rendered as grey placeholders. `Memory.fromFirestore()` never populated `signedUrl`. The screen checked `memory.signedUrl != null` — always false. `MemoryService.getDownloadUrl()` existed but was never called.

## Changes

### memory_service.dart (3 changes)
1. Added `_urlCache` field (`Map<String, String>`) for in-memory URL caching
2. Added `getDownloadUrlCached()` — checks cache before hitting Firebase Storage
3. Added `_urlCache.remove(storagePath)` in `deleteMemory()` to evict stale entries

### memory_provider.dart (1 change)
1. Wrapped `watchMemories()` stream with `.asyncMap()` that resolves all download URLs in parallel via `Future.wait()` + `getDownloadUrlCached()`, populating `signedUrl` via `Memory.copyWith()`
