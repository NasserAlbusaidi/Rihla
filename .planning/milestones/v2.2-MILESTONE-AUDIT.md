### NOTIF-02 Gap Detail

Toggle UI works correctly — persists preference to SharedPreferences, Riverpod state updates, Switch widget reflects state. However, `appBootstrapProvider` (which contains `ref.listen` on `pushNotificationsEnabled` and calls `NotificationService.initialize()`/`removeToken()`) is never watched or read by any widget in production code. The provider's `ref.listen` callback never fires.

**Fix:** Add `ref.watch(appBootstrapProvider)` inside `SafarApp.build()` in `lib/main.dart`. One line change.
