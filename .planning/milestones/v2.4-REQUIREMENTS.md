**Defined:** 2026-04-16
**Core Value:** Groups persist across events and accumulate financial history — friends settle up across trips, not just within one.

## v2.4 Requirements

Requirements sourced from `.planning/review/` open/partial items (post v2.3 review tracker). Each maps to roadmap phases.

### Architecture Refactor (Phase 36)

- [ ] **ARCH-01**: No screen file exceeds 600 lines (split or extract widgets). Applies to `group_settle_up_screen.dart` (990), `edit_expense_screen.dart` (799), `gear_screen.dart` (731), `logistics_screen.dart` (690), `create_event_screen.dart` (690). Ref: review #15.
- [x] **ARCH-02**: Home dashboard provider fan-out is bounded — per-group subscription replaces O(G×E) per-event listeners. Ref: review #16.
- [x] **ARCH-03**: `weeklyGroupSpendingProvider` uses a Firestore date-range query (or cached aggregate), not a full expenses download + client filter. Ref: review #16.
- [ ] **ARCH-04**: `CacheService` (660 lines, all static) split into focused repositories with cohesive write strategies. Deduplicate overlap with `balance_cache_repository.dart`. Ref: review #18.

### Dark Theme Migration (Phase 37)

- [ ] **DARK-01**: Every widget in `lib/` reads colors via `context.colors` (or `Theme.of(context).extension<AppColorTokens>()`). Zero direct `AppColorTokens.light.*` references remain in rendered code paths. Ref: review #17.
- [ ] **DARK-02**: Dark theme toggle (system/light/dark) exists in Settings and is persisted. Ref: review #17.
- [ ] **DARK-03**: `textMuted` (#9CA3AF, 2.86:1) removed from all functional text roles (labels, amounts, body copy). Restricted to decorative placements or replaced with a WCAG-AA-compliant muted token. Ref: review #29.
- [ ] **DARK-04**: `AppSpacingTokens.standard` actively used — hardcoded spacing numbers replaced with token refs where semantically appropriate. Ref: review #31.
- [ ] **DARK-05**: Remaining hardcoded `Color(0xFF…)` literals outside token system eliminated or justified inline (event type config maps, group card maps, onboarding gradients). Ref: review #32.

### Infrastructure (Phase 38)

- [ ] **INFRA-01**: Firebase Storage membership rules enforced via Cloud Function (or callable check) so read/write to trip buckets requires verified group membership, not just any authenticated user. Ref: review #1b.
