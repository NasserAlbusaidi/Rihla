# Requirements: Rihla v2.2 — Profile Page

**Defined:** 2026-04-01
**Core Value:** Groups persist across events and accumulate financial history — friends settle up across trips, not just within one.

## v2.2 Requirements

Requirements for this milestone. Each maps to roadmap phases.

### Identity

- [x] **IDENT-01**: User can view their current display name on the profile page
- [x] **IDENT-02**: User can edit their display name from the profile page
- [x] **IDENT-03**: Display name change propagates to all group participant records

### Stats

- [x] **STATS-01**: User can see total number of groups they belong to
- [x] **STATS-02**: User can see total number of events they've participated in
- [x] **STATS-03**: User can see total spending across all groups

### Notifications

- [x] **NOTIF-01**: User can view current push notification status
- [x] **NOTIF-02**: User can toggle push notifications on/off

### App Info

- [x] **INFO-01**: User can view app version number
- [x] **INFO-02**: User can access feedback/support link
- [x] **INFO-03**: User can view open-source licenses

### Support

- [x] **SUPP-01**: User sees a "Buy me a coffee" placeholder section on the profile page

## Future Requirements

None deferred for this milestone.
