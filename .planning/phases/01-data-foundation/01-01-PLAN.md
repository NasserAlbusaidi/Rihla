**Approach:** Since `FirebaseConfig` uses static `FirebaseAuth.instance` internally (which cannot be injected in a pure unit test), the test must validate the auth behavior at a slightly higher level. Use `MockFirebaseAuth` from `firebase_auth_mocks` to test the anonymous auth contract directly:

```dart
import 'package:firebase_auth_mocks/firebase_auth_mocks.dart';
import 'package:flutter_test/flutter_test.dart';
```

**Test structure:**

1. **"signInAnonymously succeeds and returns a user with a UID":**
   - Create `MockFirebaseAuth(signedIn: false)`
   - Call `mockAuth.signInAnonymously()`
   - Assert `mockAuth.currentUser` is not null
   - Assert `mockAuth.currentUser!.uid` is a non-empty string
   - Assert `mockAuth.currentUser!.isAnonymous` is true

2. **"no duplicate sign-in when session already active":**
   - Create `MockFirebaseAuth(signedIn: true, mockUser: MockUser(uid: 'existing-uid', isAnonymous: true))`
   - Assert `mockAuth.currentUser != null` (session already active)
   - Record the UID: `final existingUid = mockAuth.currentUser!.uid`
   - Simulate the ensureAnonymousSession logic: `if (mockAuth.currentUser == null) { await mockAuth.signInAnonymously(); }`
   - Assert `mockAuth.currentUser!.uid == existingUid` (same user, no new sign-in)

3. **"anonymous user UID persists across auth state checks":**
   - Create `MockFirebaseAuth(signedIn: false)`
   - Call `mockAuth.signInAnonymously()`
   - Record UID
   - Access `mockAuth.currentUser` again
   - Assert UID is identical (no UID churn)

4. **"authStateChanges emits user after anonymous sign-in":**
   - Create `MockFirebaseAuth(signedIn: false)`
   - Listen to `mockAuth.authStateChanges()` (collect first 2 events)
   - Call `mockAuth.signInAnonymously()`
   - Assert stream emits a non-null User with isAnonymous == true

These tests validate the behavioral contract that `ensureAnonymousSession()` implements: call `signInAnonymously()` when no user, skip when user exists, always result in a valid anonymous UID. Per D-07 and D-10 (Dart tests use mocks, not emulator).
