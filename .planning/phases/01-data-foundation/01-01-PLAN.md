**1. Create `lib/core/config/firebase_config.dart`:**

Create a static class mirroring the SupabaseConfig pattern. The class must:
- Import `cloud_firestore`, `firebase_auth`, `firebase_core`, `flutter/foundation.dart`, and `../../firebase_options.dart`
- Have static getters: `auth` returning `FirebaseAuth.instance`, `firestore` returning `FirebaseFirestore.instance`
- `initialize()` method that calls `Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform)` then immediately sets `FirebaseFirestore.instance.settings = const Settings(persistenceEnabled: true, cacheSizeBytes: Settings.CACHE_SIZE_UNLIMITED)`. Settings MUST be set before any other Firestore call (per Pitfall 2 in research)
- `ensureAnonymousSession()` method that checks `auth.currentUser != null` and returns early if user exists, otherwise calls `auth.signInAnonymously()` (per D-07)
- Static getters: `currentUser` returning `User?` (Firebase User), `isAuthenticated` returning bool, `authStateChanges` returning `Stream<User?>`
- `log()` method matching SupabaseConfig.log pattern (debug-only, timestamped, name: 'Firebase')
- Do NOT use emojis in log messages (SupabaseConfig uses them but coding style says avoid unless asked)

Use the exact implementation from the research Pattern 1 section as the starting template.

**2. Modify `lib/main.dart`:**

Per D-06 bootstrap order: Sentry -> Firebase init + Firestore settings -> Firebase anonymous auth -> Supabase init -> Supabase anonymous session -> SharedPreferences -> runApp.

Changes:
- Add import: `import 'core/config/firebase_config.dart';`
- Remove the bare `await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);` line
- Remove the `import 'firebase_options.dart';` (FirebaseConfig handles this internally)
- Replace with two calls in order:
  ```dart
  await FirebaseConfig.initialize();
  await FirebaseConfig.ensureAnonymousSession();
  ```
- Keep SupabaseConfig.initialize() and ensureAnonymousSession() AFTER Firebase calls (dual auth per D-05)
- Keep SharedPreferences, SystemChrome, runApp unchanged

**3. Create `lib/features/auth/providers/firebase_auth_provider.dart`:**

Mirror the existing auth_provider.dart pattern:
- `firebaseAuthStateProvider`: a `StreamProvider<firebase_auth.User?>` that maps `FirebaseConfig.authStateChanges`
- `firebaseCurrentUserProvider`: a `Provider<firebase_auth.User?>` that watches `firebaseAuthStateProvider.valueOrNull`
- Import firebase_auth with prefix `firebase_auth` to avoid conflict with Supabase User type
- Import `FirebaseConfig` from `../../../core/config/firebase_config.dart`
