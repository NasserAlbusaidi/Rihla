```dart
class GroupMemberBalanceCard extends StatefulWidget {

  final String currency;
  final bool isExpanded;

  final VoidCallback? onSettleUpTap; // D-22 entry point 2: tap member balance card to settle with that person

  const GroupMemberBalanceCard({
    super.key,
    required this.balance,
    required this.perEventBreakdown,
    required this.eventNames,
    required this.currency,
    required this.isExpanded,
    required this.onExpandChanged,
    this.onEventTap,
    this.onSettleUpTap,
  });
```

Visual contract:
- **Collapsed state:** Row with member name (14px w700 textPrimary) + net amount on right (14px w700, emerald if positive, rose if negative, textMuted if zero) + expand chevron (Iconsax.arrow_down_1, 16px, textMuted). When zero: show "0.000 OMR" (textMuted) + "Settled" badge (surfaceLight bg, textMuted 11px w700, radiusSmall 6px padding)
- **Card container:** white surface, radiusMedium (16px), cardShadow (if AppColors has one, else use `BoxShadow(color: Colors.black.withOpacity(0.05), blurRadius: 10, offset: Offset(0, 2))`), 1px border (AppColors.border)
- **Expand/collapse animation:** Use `AnimatedCrossFade` for the expand section with 300ms `easeOutCubic` curve. Chevron icon rotates 180 degrees when expanded.
- **Expanded state:** Below the collapsed row, show per-event rows. Each row: event name (14px w500 textSecondary) + net amount (14px w700, signed "+10.500" / "-5.000", color-coded emerald/rose) + right arrow (Iconsax.arrow_right_3, 14px, textMuted). Tappable -- calls `onEventTap(eventId)`. Per-event rows have surfaceLight background, 8px vertical padding, 16px horizontal padding.
- **Settle-up action (D-22 entry point 2):** When the card is expanded and the member has a non-zero balance, show a small "Settle" text button (primary color, 12px w700) at the bottom of the expanded section. Tapping it calls `onSettleUpTap`. This enables direct settle-up with a specific person by tapping their balance card. If `onSettleUpTap` is null or balance is zero, hide the button.
- **Accordion pattern (D-13):** Parent manages which card is expanded via `isExpanded` + `onExpandChanged`. Only one expanded at a time -- parent collapses current when another is tapped.
- **Touch target:** Minimum 44px height for expand area (accessibility)
- **Amount formatting:** Use `AppFormatters.formatCurrency(amount.abs(), currency)` with sign prefix ("+" or "-")
