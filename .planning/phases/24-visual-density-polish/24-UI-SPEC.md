## Spacing Scale

Declared values — all from `AppSpacingTokens.standard` in `lib/core/theme/tokens/spacing_tokens.dart`:

| Token | Value | Usage |
|-------|-------|-------|
| space4 | 4dp | Icon-to-text gap inside event context line; accent strip width; gap between chart bar label and bar |
| space8 | 8dp | Vertical gap between group card rows; member count badge internal padding; activity row vertical padding |
| space12 | 12dp | Inter-section gap on dashboard (D-12 — tightened from 16-24dp) |
| space16 | 16dp | Card internal padding; horizontal page margin; chart card margin |
| space20 | 20dp | Balance hero card padding |
| space24 | 24dp | Header top padding (SafeArea offset) |
| space32 | 32dp | Bottom scroll clearance above bottom nav |

Phase-specific exceptions:

| Exception | Value | Reason |
|-----------|-------|--------|
| Accent strip width | 4dp (space4) | Fixed visual spec from D-06 — a narrow left-edge strip |
| Accent strip height | Full card height (flex) | Stretches to card height via AlignedRow or ClipRRect |
| Event context line icon | 16dp icon size | D-02 — small inline type icon, space4 gap to text |
| Touch targets | 48dp minimum | Flutter Material 3 tap-target minimum — enforced on all tappable rows |

## Typography

All roles use Plus Jakarta Sans. Roles map to `AppTheme._buildTextTheme()` styles in `lib/core/theme/app_theme.dart`.

| Role | Flutter Style | Size | Weight | Line Height | Usage |
|------|--------------|------|--------|-------------|-------|
| Body | bodyMedium | 14sp | 400 | 1.4 | Balance label, context line event name, chart error text |
| Label / Secondary | bodySmall | 12sp | 400 | 1.3 | Relative date in context line, chart day labels, member count, section overline |
| Card title | titleMedium | 15sp | 600 | 1.3 | Group name in GroupCard |
| Section header | headlineLarge (override) | 28sp | 600 | 1.2 | "Your Groups (N)" — matches existing home header style |

Weight palette for this phase: regular (400) and semibold (600) only.

Note: The 28sp section header uses weight 600 (semibold) to stay within the two-weight palette. The existing 700-weight hero card heading is inherited from prior phases and is not a new decision introduced in Phase 24 — it is excluded from this phase's type scale contract.

Implementation-detail override (outside type scale): chart bar amount labels use `TextStyle(fontSize: 9, fontWeight: FontWeight.w600)` directly in `weekly_spending_card.dart`. This size falls below the declared type scale minimum and is constrained by bar column geometry — it is not a new type scale token. Do not add it to the theme or use it outside the bar chart context.

Source: `lib/core/theme/app_theme.dart` `_buildTextTheme`, CONTEXT.md Established Patterns

## Color

All values from `AppColorTokens.light` in `lib/core/theme/tokens/color_tokens.dart`. No new color constants introduced in this phase — all visuals map to existing tokens.

**Primary focal point:** BalanceHeroCard is the dominant visual element on the dashboard. All other components (GroupCard, WeeklySpendingCard, section headers) are subordinate in visual weight.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | scaffoldBackground | #FFFFFF | Page background |
| Secondary (30%) | cardSurface | #F8F9FA | GroupCard body, WeeklySpendingCard body |
| Accent (10%) | primary | #0D7B74 | Chart bars (non-zero), primary CTA gradient, accent strip slot 0 |
| Destructive | errorText | #B91C1C | "You owe" balance label (existing pattern, no change) |

Accent reserved for: non-zero chart bars, slot-0 group accent strip (teal). All other accent strips use the five-color earthy rotation below.

### Group Card Accent Strip — 5-Color Rotation (D-07)

Assigned by `groupId.hashCode.abs() % 5`. All five are existing `AppColorTokens.light` values or inline const equivalents verified against existing palette.

| Slot | Token / Value | Hex | WCAG on white |
|------|---------------|-----|---------------|
| 0 | primary | #0D7B74 | 5.12:1 AA |
| 1 | focusBorderWarm (terracotta) | #CC6B49 | 3.35:1 — strip only, not text |
| 2 | success | #10B981 | 2.39:1 — strip only, not text |
| 3 | warning | #F59E0B | 2.53:1 — strip only, not text |
| 4 | inline const #7C6E5A (warm umber) | #7C6E5A | 4.10:1 — strip only, not text |

Note: Slots 1–4 are decorative strips — no text is rendered on them. WCAG contrast applies only when color is used for text. The five values cycle visually and stay within the earthy palette. Slot 4 (#7C6E5A) is a new inline const because no warm-brown token exists in `AppColorTokens.light` — do NOT add it as a new token; use the inline const directly in `group_card.dart`.

### "No Events Yet" and Zero-Spend States

- "No events yet" context line: `textMuted` (#9CA3AF) — decorative placeholder text, not a functional label. Acceptable per existing CLAUDE.md WCAG guidance.
- Zero-spend bars: `inputFill` (#F3F4F6) — the existing 2dp gray placeholder bar, no label rendered.
- Chart bar label text on teal bar: `textOnPrimary` (#FFFFFF) — 4.5:1 on primary teal, WCAG AA.

Source: CONTEXT.md D-07, `lib/core/theme/tokens/color_tokens.dart`, CLAUDE.md WCAG constraints

## Component Inventory

### Modified: GroupCard (`lib/features/groups/widgets/group_card.dart`)

Current structure:
```
Container (card surface, 16dp padding)
  Column
    Row → group name + member count badge
    SizedBox(8)
    Text → balance label
```

New structure:
```
Container (card surface, no left padding — accent strip handles left edge)
  Row (stretch)
    Container(width: 4, color: accentColor)  ← NEW: accent strip (D-06, D-07)
    Expanded
      Padding(16dp all sides)
        Column
          Row → group name + member count badge
          SizedBox(8)
          Text → balance label
          SizedBox(4)                         ← NEW: gap before context line
          Row → [type icon 16dp] [event name + date] ← NEW: context line (D-01, D-02, D-03)
```

The `Container` wrapping the card keeps `borderRadius: BorderRadius.circular(16)` with `clipBehavior: Clip.hardEdge` so the accent strip corners are clipped correctly.

Event context line data source: `groupEventsProvider(group.id)` — sort by `createdAt` descending, take first. Render the latest event's type icon at 16dp + name + `timeago.format(event.createdAt)`.

No-events fallback: Row is replaced with `Text('No events yet', style: bodySmall, color: textMuted)`.

### Modified: WeeklySpendingCard (`lib/features/home/widgets/weekly_spending_card.dart`)

Changes:
1. Chart title changes from `'This Week'` to `'Weekly Spending (OMR)'` (D-11). Font: `TextStyle(fontWeight: FontWeight.w700, fontSize: 14, color: textPrimary)` — unchanged from current.
2. Bar column gets an additional `Text` widget above the bar container showing amount when `entry.amount > Decimal.zero` (D-09, D-10):

```
Column (mainAxisAlignment: end)
  Text(amountLabel)   ← NEW: 9sp, weight 600, textSecondary, only when amount > 0
  SizedBox(4)         ← gap between label and bar (space4 token)
  Container(barHeight, teal bar or gray placeholder)
  SizedBox(4)
  Text(dayLabel)
```

Amount label formatting: `entry.amount.toStringAsFixed(1)` — one decimal place, no currency symbol (chart title carries the OMR indicator). If the formatted value is `'0.0'` the label is suppressed.

Bar column height constraint: the outer `SizedBox(height: 80)` must increase to `SizedBox(height: 96)` to accommodate the label row above bars without clipping.

### Modified: HomeScreen (`lib/features/home/screens/home_screen.dart`)

Changes:
1. Inter-section `SizedBox` heights reduced from current 16–24dp to `space12` (12dp) between all dashboard sections (D-12). Specifically:
   - Between BalanceHeroCard → QuickActionTray: 12dp (was `SizedBox(height: 16)`)
   - Between QuickActionTray → Group cards sliver: absorbed into SliverPadding top, add `padding: EdgeInsets.only(top: 12)` to the group cards `SliverPadding`
   - Activity section `padding: EdgeInsets.fromLTRB(16, 24, 16, 8)` → `EdgeInsets.fromLTRB(16, 12, 16, 8)` (D-12)
   - Between activity section → WeeklySpendingCard: 12dp (was implicit from activity bottom padding)

2. "Your Groups (N)" section header above the group card sliver (D-13). This is a new `SliverToBoxAdapter` inserted between the quick-action sliver and the group-cards sliver:

```dart
SliverPadding(
  padding: EdgeInsets.fromLTRB(16, 12, 16, 8),
  sliver: SliverToBoxAdapter(
    child: Text(
      'Your Groups (${groups.length})',
      style: Theme.of(context).textTheme.titleMedium,
    ),
  ),
)
```

Note: The top-level `SafeArea` header already reads `'Your Groups'` as a large 28sp title. The new in-body header is `titleMedium` (15sp/600) — it functions as a sub-section label directly above the card list, providing visual separation from the quick actions above. This is a different hierarchy level from the app bar title.

Source: CONTEXT.md D-12, D-13, D-14

## Interaction Contract

### GroupCard tap
- Existing: `OpenContainer` container-transform animation (fade type, 400ms) wraps the card. No change to transition behavior.
- The accent strip is inside the `closedBuilder` return — it animates with the card on open.

### GroupCard accent strip
- Static visual element. No tap behavior. No tooltip.

### Chart bar labels
- Static text. No tap behavior on individual bars.

### "Your Groups (N)" section header
- Static text. No tap, no collapse.

### Balance loading in GroupCard
- Context line (last event row) renders independently of balance load. It uses its own `groupEventsProvider` async state.
- Loading state for events: show `'No events yet'` in `textMuted` as placeholder while the provider loads (avoids layout shift).
- Error state for events: show `'No events yet'` in `textMuted` as safe fallback.
