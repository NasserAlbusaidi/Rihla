```dart
        color: Color(0xFF6B7280), // textSecondary — inline per UI-SPEC (9sp is below type scale, not a token)

    decoration: BoxDecoration(
      color: barHeight > 0
          ? AppColorTokens.light.primary
          : AppColorTokens.light.inputFill,
      borderRadius: const BorderRadius.vertical(
        top: Radius.circular(4),
      ),
    ),
  ),
  const SizedBox(height: 4),
  Text(
    dayLabel,
    style: TextStyle(
      fontSize: 10,
      color: AppColorTokens.light.textMuted,
    ),
  ),
],
```

The `if (entry.amount > Decimal.zero)` guard ensures zero-spending bars show no label (D-10). The `toStringAsFixed(1)` formats as "12.5", "3.0", etc. The 9sp/w600 style is intentionally below the type scale — it is constrained by bar column geometry and must NOT be added as a theme token (per UI-SPEC).
