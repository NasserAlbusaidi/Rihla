**GroupService class** (mirrors TripService pattern):
- Constructor takes `Ref _ref`

- Private method `String _generateInviteCode()` — copy exact logic from TripService: `const chars = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';` (excludes O/0/I/l per D-10), 6 chars, `Random.secure()`. OR import and reuse if TripService exposes it.

**`Future<Group> createGroup({required String name, required String currency})` method:**
1. Get UID from `FirebaseConfig.currentUser?.uid` — throw if null
2. Get display name from `_ref.read(settingsProvider).deviceName` (per D-06)
3. Generate IDs: `groupId = const Uuid().v4()`, `memberId = const Uuid().v4()`, `inviteCode = _generateInviteCode()`
4. Create `WriteBatch batch = _db.batch()`
5. Document 1 — group: `batch.set(_db.collection('groups').doc(groupId), { 'id': groupId, 'name': name, 'inviteCode': inviteCode, 'createdBy': uid, 'memberIds': [uid], 'currency': currency, 'createdAt': FieldValue.serverTimestamp(), 'updatedAt': FieldValue.serverTimestamp() })`
6. Document 2 — inviteCode lookup: `batch.set(_db.collection('inviteCodes').doc(inviteCode), { 'groupId': groupId, 'createdAt': FieldValue.serverTimestamp() })`
7. Document 3 — creator member: `batch.set(_db.collection('groups').doc(groupId).collection('members').doc(memberId), { 'id': memberId, 'userId': uid, 'displayName': displayName, 'role': 'CREATOR', 'joinedAt': FieldValue.serverTimestamp(), 'isShadow': false })`
8. `await batch.commit()`
9. Return a Group object constructed from local data (use `DateTime.now()` for createdAt since serverTimestamp won't be available in the returned object immediately)

**`Future<Group> joinGroup({required String inviteCode})` method:**
1. Get UID and display name (same as createGroup)
2. Read inviteCode doc: `final codeDoc = await _db.collection('inviteCodes').doc(inviteCode.toUpperCase()).get()`
3. If `!codeDoc.exists` throw `Exception('Invalid invite code')` (per UI-SPEC error copy)
4. Extract `groupId` from codeDoc data
5. Read group doc to check existing membership: `final groupDoc = await _db.collection('groups').doc(groupId).get()`
6. Extract `memberIds` as `List<String>.from(groupDoc.data()!['memberIds'] as List)`
7. If `memberIds.contains(uid)` throw `Exception('Already a member')` (per UI-SPEC "You're already in this group.")
8. Create `WriteBatch batch = _db.batch()`
9. Add member doc: `batch.set(_db.collection('groups').doc(groupId).collection('members').doc(const Uuid().v4()), { 'id': memberId, 'userId': uid, 'displayName': displayName, 'role': 'MEMBER', 'joinedAt': FieldValue.serverTimestamp(), 'isShadow': false })`
10. Update memberIds: `batch.update(_db.collection('groups').doc(groupId), { 'memberIds': FieldValue.arrayUnion([uid]), 'updatedAt': FieldValue.serverTimestamp() })`
11. `await batch.commit()`
12. Fetch and return updated group: `Group.fromDoc(await _db.collection('groups').doc(groupId).get())`

**`Future<void> updateGroup({required String groupId, String? name, String? currency})` method** (for D-15, D-16 group settings):
1. Build update map with only non-null fields + `'updatedAt': FieldValue.serverTimestamp()`
2. `await _db.collection('groups').doc(groupId).update(updateMap)`

**`Future<void> updateMemberDisplayName({required String groupId, required String memberId, required String displayName})` method** (for D-07):
1. `await _db.collection('groups').doc(groupId).collection('members').doc(memberId).update({ 'displayName': displayName })`

```dart
final userGroupsProvider = StreamProvider<List<Group>>((ref) {
  final uid = FirebaseConfig.currentUser?.uid;
  if (uid == null) return Stream.value([]);
  return FirebaseConfig.firestore
      .collection('groups')
      .where('memberIds', arrayContains: uid)
      .orderBy('createdAt', descending: true)
      .snapshots()
      .map((snapshot) => snapshot.docs.map((doc) => Group.fromDoc(doc)).toList());
});
```
