## Screen Layouts

### HomeScreen (groups-first replacement)

Structure:
```
Scaffold
  SafeArea
    Column
      _buildHeader()           // "Your Groups" title + (no action — FAB handles create/join)
      OfflineBanner            // existing widget
      Expanded
        RefreshIndicator
          when(data) → ListView.builder → GroupCard
          when(loading) → SkeletonLoader (3 cards)
          when(error) → EmptyStateView (error variant)
          empty data → EmptyStateView ("No groups yet")
      FloatingActionButton     // bottom-right, opens FAB bottom sheet
```

Header: "Your Groups" in `headlineLarge` (28sp, w800, `textPrimary`). No subtitle. No search bar (Phase 2 has <15 groups per user).

FAB bottom sheet: `AppBottomSheetRoute`. Two full-width rows — "Create a Group" (Iconsax.people, primary) and "Join a Group" (Iconsax.login, secondary). Dismiss on tap outside or drag down. Each row is 64px tall with 16px horizontal padding.

### CreateGroupScreen

Structure:
```
Scaffold
  AppBar (title: "New Group", leading: close X)
  SingleChildScrollView
    Padding(24px horizontal)
      Form
        SizedBox(height: 32)  // top breathing room
        Text("Group Name")    // titleSmall label
        SizedBox(height: 8)
        TextFormField          // group name input
        SizedBox(height: 24)
        Text("Currency")      // titleSmall label
        SizedBox(height: 8)
        DropdownButtonFormField // currency selector (OMR default)
        SizedBox(height: 32)
        Text("Your name in this group") // titleSmall label
        SizedBox(height: 8)
        Container(read-only)   // device name displayed, not editable
        SizedBox(height: 48)
        LoadingButton("Create Group")
```

No date fields. No member name list (self-naming via device profile, D-05/D-06). Creator name shown read-only to confirm identity.

### Post-Creation Share Prompt

Presented as bottom sheet (pushed via `AppBottomSheetRoute`) immediately after successful group creation.

Structure:
```
Padding(24px)
  Column
    Text(groupName, headlineSmall)
    SizedBox(8)
    Text("Share this code with your group", bodyMedium, textSecondary)
    SizedBox(24)
    InviteCodeDisplay(code)    // formatted 6-char code in mintSurface pill
    SizedBox(24)
    Row
      Expanded → ElevatedButton("Copy Code")    // copies to clipboard, shows toast
      SizedBox(12)
      Expanded → OutlinedButton("Share")        // native OS share sheet
    SizedBox(16)
    TextButton("Done")         // dismisses and navigates to group detail
```

### JoinGroupScreen

Structure:
```
Scaffold
  AppBar (title: "Join a Group", leading: back)
  SingleChildScrollView
    Padding(24px horizontal)
      SizedBox(height: 32)
      Text("Enter the invite code") // headlineSmall
      SizedBox(8)
      Text("Ask a group member for their 6-character code", bodyMedium, textSecondary)
      SizedBox(32)
      TextFormField               // 6-char code input, uppercase auto-transform, letter-spacing 8px
      SizedBox(48)
      LoadingButton("Join Group")
```

Single step (no name claiming, D-13). On success, navigate to group detail via GoRouter replace.

### GroupDetailScreen

Structure:
```
Scaffold
  ModuleHeader                   // dark gradient, group name + created date
  Body
    SingleChildScrollView
      Padding(horizontal: 24)
        SizedBox(8)
        _buildStatsRow()         // member count chip + currency chip + creation date
        SizedBox(24)
        _buildInviteSection()    // "Invite Code" section header + InviteCodeDisplay + share button
        SizedBox(24)
        _buildMembersSection()   // "Members" section header + ListView of GroupMemberTile
        SizedBox(24)
        _buildEventsSection()    // "Events" section header + EmptyStateView (placeholder)
        SizedBox(32)
```

Stats row: Two chips side by side. Left chip: Iconsax.people icon + "{N} members". Right chip: currency code (e.g. "OMR"). Both use `surfaceLight` background, `textSecondary` text, `radiusSmall` (12px) corners.

Event timeline placeholder: `EmptyStateView` with icon `Iconsax.calendar_add`, title "No events yet", message "Create an event to get started — events will appear here." No CTA button (events are Phase 3).

Settings access: Three-dot icon in AppBar trailing. Navigates to `GroupSettingsScreen`.

### GroupSettingsScreen

Structure:
```
Scaffold
  AppBar (title: "Group Settings")
  ListView
    ListTile("Group Name", trailing: edit icon) → inline rename or navigate
    ListTile("Currency", trailing: current currency) → dropdown sheet
    Divider

```

Destructive section: None in Phase 2 (no group deletion, D-18; no member removal, D-17).

## Interaction Contract

### FAB Behavior

Tap FAB → open bottom sheet with two options (Create / Join). Both options dismiss the sheet then push their respective screen. Sheet dragable to dismiss. `HapticFeedback.lightImpact()` on FAB tap (matches existing `HapticService` usage throughout app).

### Invite Code Input

- Auto-uppercase on entry (`TextInputFormatter.upperCaseFormatter` or `textCapitalization: TextCapitalization.characters`)
- `TextInputType.text` (not number — alphanumeric)
- Max length: 6 characters
- Letter spacing: 8px in input field to visually separate characters
- On paste: trim whitespace, take first 6 chars, uppercase
- Submit triggers immediately if exactly 6 chars entered (no manual tap needed — `onChanged` validation)

### Copy Code Toast

`ScaffoldMessenger.of(context).showSnackBar()` using app's existing `snackBarTheme` (dark background, floating, `radiusMedium`). Duration: 2 seconds. No action button on toast.

### Navigation Flow

```
HomeScreen
  FAB → bottom sheet → "Create a Group" → CreateGroupScreen
                                             → success → post-creation share sheet
                                                          → "Done" → GroupDetailScreen
  FAB → bottom sheet → "Join a Group" → JoinGroupScreen
                                         → success → GroupDetailScreen (replace)
  GroupCard tap → GroupDetailScreen
    AppBar trailing icon → GroupSettingsScreen
```

GoRouter routes to add: `/create-group`, `/join-group`, `/group/:id`, `/group/:id/settings`

GroupDetailScreen and GroupSettingsScreen use `Navigator.push` (not GoRouter), consistent with the existing pattern where all screens below the top-level hub use imperative navigation.

### Animations

Match existing home screen animation style (`flutter_animate ^4.5.0`):
- GroupCard list entry: `fadeIn(duration: 400ms) + slideY(begin: 0.05, end: 0, curve: easeOutCubic)` with staggered delay per card (50ms per index, max 5 cards staggered)
- Screen entry: `fadeIn(600ms) + slideY(begin: -0.1)` for headers (matches existing `_buildHeader` animation)
- Empty state: `fadeIn(400ms) + scale(begin: 0.95)` (matches `EmptyStateView` built-in animation)

Reduce motion: All animations gated on `!MediaQuery.of(context).disableAnimations` (existing pattern in `EmptyStateView`).

### Loading States

- Groups list loading: `SkeletonLoader` showing 3 placeholder cards (matches existing trip list behavior)
- Create group submit: `LoadingButton` shows spinner, button disabled during in-flight Firestore batch write
- Join group submit: `LoadingButton` shows "Joining…", button disabled
- Group detail loading: `ModuleHeader` always renders (group name from navigation params); member list shows `SkeletonLoader` until `groupMembersProvider` resolves
