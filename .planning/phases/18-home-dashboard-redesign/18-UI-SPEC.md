## Spacing Scale

Declared values (all multiples of 4dp — source: `AppSpacingTokens.standard`):

| Token | Value | Usage |
|-------|-------|-------|
| space4 | 4dp | Inline element gaps, between name and member count in GroupCard |
| space8 | 8dp | Between title bar and group list, activity overline bottom margin, between skeleton bars within card |
| space12 | 12dp | Between group cards (vertical list), between activity rows, between "Retry" CTA and secondary link |
| space16 | 16dp | Card horizontal margin, card internal padding, OfflineBanner horizontal padding, screen horizontal padding |
| space20 | 20dp | Icon container to title gap in EmptyStateView |
| space24 | 24dp | Title horizontal padding, activity section top padding, EmptyStateView outer padding (all sides), message to CTA gap |
| space32 | 32dp | Title vertical top padding (from safe area) |

Exceptions:
- Quick-action button touch targets: 48dp minimum height (WCAG 2.1 AA tap target)
- Activity row height: 48dp minimum (WCAG tap target)
- OfflineBanner height: 44dp fixed
- Bottom navigation bar height: 56dp (OS standard)
- FAB border radius: 28dp (circular)
- Balance hero card border radius: `radiusLarge` (16dp)
- Group card border radius: `radiusLarge` (16dp)
- Button height: `buttonHeight` (52dp)

## Screen Layout Contract

### Scroll Architecture

`CustomScrollView` + `SliverList.builder` for the full-screen scroll. No nested scrollables except the weekly spending card if the chart requires it.

```
Scaffold(key: HomeKeys.screen, backgroundColor: AppColors.background)
  ├── OfflineBanner()                        [conditional — shown on error state]
  └── Column
        ├── SafeArea
        │     └── Padding(h: space24, v: space16)
        │           └── Row(mainAxisAlignment: spaceBetween)
        │                 ├── Text("Your Groups", 28sp, w800, textPrimary)
        │                 └── FloatingActionButton.small(primary)
        └── Expanded
              └── CustomScrollView
                    ├── SliverToBoxAdapter → BalanceHeroCard         [D-01, D-02, D-03]
                    ├── SliverToBoxAdapter → QuickActionTray         [D-04 through D-07]
                    ├── SliverPadding(h: space16)
                    │     └── SliverList.builder → FadeInList        [D-22]
                    │           └── TapBounce → GroupCard            [D-08, D-09, D-23]
                    ├── SliverToBoxAdapter → ActivitySection         [D-13 through D-15]
                    │     ├── Text("RECENT ACTIVITY", overline, textMuted)
                    │     └── Column → ActivityRow × 5
                    └── SliverToBoxAdapter → WeeklySpendingCard      [D-16, D-17]
  └── BottomNavigationBar (bottomNavShell)                           [D-10, D-11, D-12]
```

### Balance Hero Card States

| Balance Condition | Background | Amount Color | Icon | Text |
|-------------------|------------|--------------|------|------|
| You owe (net negative) | `cardSurface` #F8F9FA | `errorText` #B91C1C | warning indicator | "You owe OMR X.XXX across N groups" |
| You are owed (net positive) | `cardSurface` #F8F9FA | `successText` #047857 | checkmark or up-arrow | "You are owed OMR X.XXX across N groups" |
| All settled (zero) | `cardSurface` #F8F9FA | `textSecondary` #6B7280 | checkmark (Iconsax.tick_circle) | "All settled up" + "OMR 0.000" |

Card is always visible — does not hide when settled (D-02).

### Quick-Action Tray Layout

4 icon buttons in a `Row(mainAxisAlignment: spaceAround)`, horizontal padding `space16`. Each button: `TapBounce` wrapping `Column[Icon + Text]`. Icon size 24dp. Touch target minimum 48dp × 48dp.

| Button | Icon | Label | Action |
|--------|------|-------|--------|
| Add Expense | Iconsax.receipt_add | "Add Expense" | Opens group picker bottom sheet → routes to add expense for selected group's active event |
| Settle Up | Iconsax.money_recive | "Settle Up" | Opens group picker bottom sheet → routes to settle up for selected group |
| Invite | Iconsax.user_add | "Invite" | Opens existing invite code flow |
| Activity | Iconsax.activity | "Activity" | Scrolls to activity section |

Entire tray must be on-screen without scrolling on a ~390px width phone (D-07).

### Bottom Navigation

4 tabs: Groups (active), Activity (placeholder), Chats (placeholder), Profile (placeholder).

| Tab | Icon | Active Color | Inactive Color |
|-----|------|-------------|----------------|
| Groups | Iconsax.people | `bottomNavActiveIcon` #0D7B74 | `bottomNavInactiveIcon` #9CA3AF |
| Activity | Iconsax.activity | `bottomNavActiveIcon` #0D7B74 | `bottomNavInactiveIcon` #9CA3AF |
| Chats | Iconsax.message | `bottomNavActiveIcon` #0D7B74 | `bottomNavInactiveIcon` #9CA3AF |
| Profile | Iconsax.profile_circle | `bottomNavActiveIcon` #0D7B74 | `bottomNavInactiveIcon` #9CA3AF |

Bar background: `bottomNavBackground` #FFFFFF. Height: 56dp. Inactive tabs tap → placeholder screen showing "Coming soon" in center (`textSecondary`, 14sp, w400).

## Screen State Contract

| State | Trigger | What Renders |
|-------|---------|-------------|
| Loading | Initial data fetch | Title + FAB (immediate), `SkeletonLoader.dashboardHero()` in hero area, `SkeletonLoader.groupList(count: 3)`, no activity strip, no spending card, bottom nav visible |
| Loaded | `userGroupsProvider` emits groups | Full dashboard: hero card + quick-action tray + FadeInList of GroupCards + activity strip (5 entries) + weekly spending card |
| Empty | `userGroupsProvider` emits empty list | Title + FAB + `EmptyStateView` (no hero, no tray, no activity, no spending card), bottom nav visible |
| Error | `userGroupsProvider` emits error | `OfflineBanner` pinned + title + FAB + `EmptyStateView` in error config (two CTAs) |

State transitions: `AsyncValue.when(data:, loading:, error:)` pattern.

## Interaction Contract

| Trigger | Response | Transition |
|---------|----------|-----------|
| Tap group card | Navigate to Group Detail | `AppPageRoute` (slide-right) |
| Tap FAB (+) | Open Create/Join Group bottom sheet | `AppBottomSheetRoute` (slide-up) |
| Tap "Add Expense" quick-action | Open group picker bottom sheet | `AppBottomSheetRoute` (slide-up) |
| Tap "Settle Up" quick-action | Open group picker bottom sheet | `AppBottomSheetRoute` (slide-up) |
| Tap "Invite" quick-action | Open invite code flow | `AppBottomSheetRoute` (slide-up) |
| Tap "Activity" quick-action | Scroll to activity section | Animated scroll, no navigation |
| Tap activity row | Navigate to the referenced group | `AppPageRoute` (slide-right) |
| Pull to refresh | `ref.invalidate(userGroupsProvider)` | Standard `RefreshIndicator` |
| Tap "Retry" | `ref.refresh(userGroupsProvider)` | Loading state → data or error |
| Tap "Create Group" (empty) | Open create group flow | `AppBottomSheetRoute` (slide-up) |
| Tap "Groups" nav tab | No-op (already active) | No transition |
| Tap "Activity" nav tab | Navigate to placeholder screen | `AppPageRoute` (slide-right) |
| Tap "Chats" nav tab | Navigate to placeholder screen | `AppPageRoute` (slide-right) |
| Tap "Profile" nav tab | Navigate to placeholder screen | `AppPageRoute` (slide-right) |
| Data loads | Crossfade skeleton → content | Fade 300ms |
| Connection restored | OfflineBanner fades out | Fade 300ms |
| Group card entrance | FadeInList stagger | 350ms duration, 50ms stagger per card, easeOutCubic |
| Any card/button press | TapBounce | Scale 0.97, 120ms, easeInOut |

## Performance Contract

Source: CONTEXT.md D-21, ROADMAP.md Phase 18 success criteria #4.

- `CustomScrollView` + `SliverList.builder` for the main scroll — no nested `ListView` inside `Expanded` (D-21)
- `SkeletonLoader.groupList()` in `loading:` callback — no spinner, no blank screen (NAV-05 complete)
- Target: 60fps, no frame exceeding 16ms on Snapdragon 665-class device
- `FadeInList` entrance animation must not block first paint — animation is additive, not blocking
- Weekly spending card chart: use `Container` bars (proportional height, teal fill) as default approach; avoid `fl_chart` unless native bars fail to render within 16ms budget. Chart rendering approach left to executor discretion (Claude's Discretion from CONTEXT.md).
