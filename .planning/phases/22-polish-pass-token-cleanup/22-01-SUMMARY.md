# Phase 22 Plan 01: Foundation Widgets & Token Gaps Summary

Grain texture asset, GrainOverlay widget, AnimatedCurrencyText widget, and 5 missing AppColorTokens added via TDD — all primitives required by plans 02-05 are now available.

## What Was Built

### Task 1: Grain PNG + GrainOverlay + AnimatedCurrencyText (TDD)

**Grain texture asset (`assets/textures/grain.png`):**
- 32x32 RGBA PNG generated by `tool/generate_grain.dart` using Dart's `zlib` encoder
- Fixed seed (42) for reproducibility across environments
- ~20% pixel density with white pixels at varying alpha (100-254 range) on transparent background
- 708 bytes — tiny tileable asset
- Registered in `pubspec.yaml` under `flutter: assets:`

**GrainOverlay widget (`lib/shared/widgets/grain_overlay.dart`):**
- `StatelessWidget` wrapping child in `DecoratedBox` with `DecorationImage`
- `AssetImage('assets/textures/grain.png')` with `ImageRepeat.repeat`
- Configurable `opacity` parameter (default `0.035` for heroes/scaffold, use `0.02` for dark headers per D-11)
- `Alignment.topLeft` + `BoxFit.none` for correct tile anchoring

**AnimatedCurrencyText widget (`lib/shared/widgets/animated_currency_text.dart`):**
- `StatefulWidget` with `_previousValue` tracking via `didUpdateWidget`
- `TweenAnimationBuilder<double>` with `Curves.easeOutCubic`, 600ms default (D-13)
- Sign-based color using Dart 3 switch: `> 0 => successText`, `< 0 => errorText`, `_ => textSecondary` (D-15)
- Formats via `AppFormatters.formatCurrency` during interpolation
- Accepts `TextStyle?` style override with color injected at render time

**Tests (15 passing):**
- `grain_overlay_test.dart`: child render, DecoratedBox presence, asset path `'assets/textures/grain.png'`, `ImageRepeat.repeat`, default opacity 0.035, custom opacity
- `animated_currency_text_test.dart`: render without errors, TweenAnimationBuilder present, formatted currency output, default/custom duration, TextStyle acceptance, value-change animation, zero-value color
