**GrainOverlay widget** (`lib/shared/widgets/grain_overlay.dart`):
```dart
import 'package:flutter/material.dart';

/// Applies a subtle paper grain texture overlay to its child.
///
/// Uses a tileable 32x32 noise PNG repeated across the surface.
/// Default opacity is 3.5% (hero cards/scaffold). Use 2% for dark headers (per D-11).
class GrainOverlay extends StatelessWidget {
  final Widget child;
  final double opacity;

  const GrainOverlay({super.key, required this.child, this.opacity = 0.035});

  @override
  Widget build(BuildContext context) {
    return DecoratedBox(
      decoration: BoxDecoration(
        image: DecorationImage(
          image: const AssetImage('assets/textures/grain.png'),
          repeat: ImageRepeat.repeat,
          opacity: opacity,
          fit: BoxFit.none,
          alignment: Alignment.topLeft,
        ),
      ),
      child: child,
    );
  }
}
```

**AnimatedCurrencyText widget** (`lib/shared/widgets/animated_currency_text.dart`):
Create a `StatefulWidget` that:
- Takes `Decimal value`, `String currency`, optional `TextStyle? style`, optional `Duration duration` (default 600ms)
- Tracks `_previousValue` as `double` in state
- Uses `didUpdateWidget` to set `_previousValue = old.value.toDouble()` when value changes
- Renders `TweenAnimationBuilder<double>(begin: _previousValue, end: widget.value.toDouble(), duration: widget.duration, curve: Curves.easeOutCubic)`
- Inside builder: compute color from animated value sign using Dart 3 switch on `value.compareTo(0.0)`: `> 0 => AppColorTokens.light.successText`, `< 0 => AppColorTokens.light.errorText`, `_ => AppColorTokens.light.textSecondary`
- Format: `AppFormatters.formatCurrency(Decimal.parse(value.abs().toStringAsFixed(3)), widget.currency)`
- Apply color to style via `(widget.style ?? const TextStyle()).copyWith(color: color)`

Import `package:decimal/decimal.dart`, `package:safar/core/theme/tokens/color_tokens.dart`, `package:safar/core/utils/formatters.dart`.
