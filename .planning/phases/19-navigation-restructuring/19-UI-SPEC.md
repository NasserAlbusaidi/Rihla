# Phase 19 — UI Design Contract

> Visual and interaction contract for Phase 19: Navigation Restructuring.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> NOTE: This phase is a pure routing refactoring — no screens are redesigned. The
> contract governs one net-new visual element (the in-screen not-found error state,
> per D-11) and confirms the interaction contracts for transitions, back-button
> behaviour, and bottom nav placeholder tabs. All other visual decisions are inherited
> from the established design system and do not change in this phase.

## Interaction Contracts

### Transition Animation (D-03)

Every GoRouter route — both existing and all 14 new subroutes added in Phase 19 —
uses the same `SlideTransition` builder via `CustomTransitionPage`:

```
Direction:    right → left (forward navigation)
              left → right (back navigation, system-managed)
Offset begin: Offset(1, 0)
Offset end:   Offset.zero
Curve:        Curves.easeOutCubic
Duration:     Default Flutter page transition duration (~300ms)
```

This is extracted as a module-level `_slideRightTransition` helper function in
`app_router.dart` to avoid repeating the builder across all route entries.

**Exception — FullScreenPhoto overlay (MemoriesScreen):** Stays as `Navigator.push`
with `PageRouteBuilder(opaque: false)`. This is an in-screen overlay lightbox with
transparent background — not a navigation route. GoRouter cannot produce an
`opaque: false` page. No transition change.

### Back Button Behaviour

All screens receive GoRouter-managed back navigation. The system back button and the
`ModuleHeader` back button both call `context.pop()` (GoRouter's pop, not
`Navigator.of(context).pop()`). The `ModuleHeader` widget's existing `Navigator.of(context).pop()` call must be updated to `context.pop()` in every screen that migrates to GoRouter.

**ModuleHeader back button tap target:** 44×44dp (existing).

### Bottom Navigation (D-04)

Four tabs, unchanged from Phase 18:

| Tab | Icon | Label | State |
|-----|------|-------|-------|
| Groups | Iconsax.people | "Groups" | Live (real GroupsScreen) |
| Activity | Iconsax.activity | "Activity" | Placeholder |
| Chats | Iconsax.message | "Chats" | Placeholder |
| Profile | Iconsax.user | "Profile" | Placeholder |

Placeholder tabs show the "Coming soon" state (see Copywriting section). No wiring
of real screens in this phase. Placeholder content renders at 14sp / weight 400 /
`textSecondary` (#6B7280).

## Copywriting Contract

Phase 19 introduces one new visible state: the in-screen not-found error (D-11).
All other copy is inherited from existing screens and does not change.

| Element | Copy | Notes |
|---------|------|-------|
| Primary CTA (not-found state) | "Go Home" | Single verb + destination noun. Routes to `/home`. |
| Not-found heading | "This event no longer exists" | Used when `eventDetailProvider` returns null for a deep-linked event. |
| Not-found body | "It may have been deleted. Tap below to go back to your groups." | Problem description + next step. 14sp bodyMedium. |
| Not-found group variant heading | "This group is no longer available" | Used when `groupDetailProvider` returns null. |
| Not-found group variant body | "You may have been removed. Tap below to go back home." | 14sp bodyMedium. |
| Placeholder tab heading | "Coming soon" | Shown in Activity, Chats, and Profile tabs. 18sp headlineSmall. |
| Placeholder tab body | "This feature is on its way." | 14sp bodyMedium / textSecondary. |
| Error loading state | "Something went wrong" | When provider returns an error (not null). Existing pattern from EmptyStateView. |
| Error loading body | "Pull to refresh or try again later." | Shown below error heading. 14sp bodyMedium. |

**Destructive actions in Phase 19:** None. This phase has no delete, remove, or
irreversible actions. No confirmation dialogs are needed.

**EditExpenseSheet renamed to EditExpenseScreen:** The widget becomes a full-page
GoRouter route per D-07. The screen title in `ModuleHeader` remains "Edit Expense"
(no copy change — only the navigation pattern changes).

## Route → Screen → Error State Mapping

For each screen that migrates to GoRouter, the error state contract is:

**Not-found state focal point:** Primary visual anchor is the `Iconsax.warning_2` icon;
hierarchy flows icon → heading → body → CTA.

| Screen | null-event state | error state |
|--------|-----------------|-------------|
| EventCommandCenter | "This event no longer exists" + Go Home | "Something went wrong" + pull to refresh |
| LedgerScreen | "This event no longer exists" + Go Home | "Something went wrong" |
| GearScreen | "This event no longer exists" + Go Home | "Something went wrong" |
| LogisticsScreen | "This event no longer exists" + Go Home | "Something went wrong" |
| VaultScreen | "This event no longer exists" + Go Home | "Something went wrong" |
| MemoriesScreen | "This event no longer exists" + Go Home | "Something went wrong" |
| ActivityScreen (event-level) | "This event no longer exists" + Go Home | "Something went wrong" |
| GroupDetailScreen | "This group is no longer available" + Go Home | "Something went wrong" |
| GroupSettleUpScreen | "This group is no longer available" + Go Home | "Something went wrong" |

All not-found states use `EmptyStateView` with:
- Icon: `Iconsax.warning_2` at `textSecondary` (#6B7280)
- Heading: as per table above, 18sp / weight 600
- Body: as per Copywriting table, 14sp / weight 400
- CTA: "Go Home" — `ElevatedButton` 52dp height navigating to `/home` via `context.go('/home')`
