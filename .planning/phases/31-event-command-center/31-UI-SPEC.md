## Spacing Scale

All values from `AppSpacingTokens.standard` in `lib/core/theme/tokens/spacing_tokens.dart`. Source: codebase.

| Token | Value | Usage |
|-------|-------|-------|
| space4 | 4dp | Icon gaps, overline-to-value gaps, chip internal padding |
| space8 | 8dp | Within-card row gaps, tight label-to-content gaps |
| space12 | 12dp | Header top padding, compact section padding |
| space16 | 16dp | Card internal padding, between-section gaps, horizontal inset |
| space20 | 20dp | Header body padding top (dark header after back button row) |
| space24 | 24dp | Horizontal screen padding, between-card vertical gaps |
| space32 | 32dp | Bottom scroll buffer, header bottom padding (dark) |

Border radii (from AppSpacingTokens.standard):
- `radiusSmall` = 8dp — chips, type badge pill
- `radiusMedium` = 12dp — buttons, input fields
- `radiusLarge` = 16dp — cards (EventExpenseHero, SmartModuleCard, section containers), back button container

Button height: 52dp (AppSpacingTokens.standard.buttonHeight)

Exceptions:
- Touch targets (back button, gear icon, FAB): minimum 44dp square
- FAB: 56dp (Flutter FloatingActionButton default)
- Dark header bottom padding: 32dp (matches established ModuleHeader dark pattern)
- space12 (12dp) and space20 (20dp): established tokens from AppSpacingTokens.standard — on-grid at 4dp increments, used as defined by the token system

## Typography

All text uses Plus Jakarta Sans. Source: `AppTheme._buildTextTheme` + established screen patterns.

Declared type scale — 4 sizes, 2 weights:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 28sp | 700 | 1.2 | Event name in header, settings screen page title |
| Heading | 20sp | 700 | 1.2 | Section titles in EventSettingsScreen |
| Body | 14sp | 400 | 1.5 | Description fields, date range, supporting text |
| Label | 13sp | 700 | 1.3 | Subtitle in dark header (type badge · group name), overline caps, section header overlines |

Inherited implementation details (not new spec declarations — do not add to the declared scale):
- Overline caps for hero card: 10sp / letterSpacing 0.5 / textMuted — matches existing EventExpenseHero TOTAL EXPENSES overline. Do not change.
- Header subtitle in dark: `Colors.white.withValues(alpha: 0.5)` — matches existing ModuleHeader dark subtitle pattern. Do not change.

Weight remap: all previous weight 600 and weight 800 usages map to weight 700 (emphasis/bold). Weight 400 is regular/body.

## Color

Source: `AppColorTokens.light` in `lib/core/theme/tokens/color_tokens.dart`.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | scaffoldBackground | #FFFFFF | Page background (EventCommandCenter, EventSettingsScreen body) |
| Secondary (30%) | cardSurface | #F8F9FA | EventExpenseHero card, SmartModuleCard background, settings section containers |
| Accent (10%) | primary | #0D7B74 | Reserved — see accent list below |
| Destructive | errorText | #B91C1C | Delete event button text and icon only |

### Accent (primary #0D7B74) is reserved exclusively for:
- FAB background (+ add expense)
- "+ Add Expense" ActionChip background in EventExpenseHero
- Ledger module card accent dot and icon (moduleLedger token)
- Gear icon tap state (focus ring only — icon itself remains white on dark header)
- Save button in EventSettingsScreen edit fields
- TextButton "Try again" in error states

### Secondary semantic colors:
| Token | Hex | Usage |
|-------|-----|-------|
| headerGradientStart | #111827 | Dark ModuleHeader gradient start |
| headerGradientEnd | #1F2937 | Dark ModuleHeader gradient end |
| textPrimary | #111827 | All functional body text, event name |
| textSecondary | #6B7280 | Expense count, module summary text, secondary labels |
| textMuted | #9CA3AF | Overline caps only — not for functional labels or amounts |
| border | #E5E7EB | Card borders, dividers, section container borders |
| warning | #F59E0B | Balance-gate warning banner (unsettled balances on delete attempt) |
| moduleLedger | #0D7B74 | Ledger SmartModuleCard accent |
| moduleGear / moduleLogistics / moduleVault / moduleActivity / moduleMemories | #6B7280 | All non-Ledger module card accents |

### Dark header: text-on-dark
- Event name: `Colors.white` (100% opacity)
- Subtitle (type · group): `Colors.white.withValues(alpha: 0.5)`
- Back button icon: `Colors.white`
- Gear icon: `Colors.white`
- Back button container border: `Colors.white.withValues(alpha: 0.08)`
- Back button container fill: `Colors.white.withValues(alpha: 0.05)`

WCAG compliance: white text on #111827 = 16.1:1 — passes AAA. White at 50% opacity on #111827 = approximately 3.5:1 — passes AA large (subtitle is 13sp/700 which qualifies as large text per WCAG). Confirmed against established CLAUDE.md WCAG table.

### Focal Point

Primary visual anchor: EventExpenseHero card — animated total expense amount draws the eye first. The counter animation (TweenAnimationBuilder 0→total, 800ms) combined with the card's dominant size in the scroll hierarchy establishes it as the primary visual entry point on the screen.

## Screen Inventory

### Screen 1: EventCommandCenter (refresh)

Layout: `Scaffold` → `CustomScrollView` with slivers. No AppBar. No bottom nav (hub screen).

Sliver order:
1. `SliverToBoxAdapter` — `ModuleHeader` (dark, useDarkTheme: true)
2. `SliverToBoxAdapter` — `OfflineBanner`
3. `SliverPadding(24, 20, 24, 0)` — `EventExpenseHero`
4. `SliverPadding(24, 24, 24, 0)` — `EventModuleList` (2-column grid)
5. `SliverToBoxAdapter` — `SizedBox(height: 32)` (scroll buffer)

Header changes from current:
- Replace `Iconsax.more_circle` action with `Iconsax.setting_2` gear icon
- Header subtitle format: `"${config.label} \u00B7 ${group?.name ?? ''}"` (unchanged)
- Add date range as a second subtitle line below type · group line: `"Mar 15 – Mar 20"` format (en-dash U+2013, abbreviated month name, no year if same year as current)
- Settings icon 44dp touch target, white, navigates to `/group/:gid/event/:eid/settings`

FAB: keep `Iconsax.add` on primary background, navigates to ledger/add.

### Screen 2: EventSettingsScreen (new)

Layout: `Scaffold` → `SafeArea` → `SingleChildScrollView`. No AppBar. Matches GroupSettingsScreen pattern.

Horizontal padding: 24dp throughout. Top padding: 16dp.

Section order:
1. Back button row (44dp touch target, inputFill container, radiusMedium = 16dp radius)
2. `SizedBox(height: 16)`
3. Page title: "Event Settings" — 28sp / weight 700 / textPrimary
4. `SizedBox(height: 24)`
5. `EventInfoSection` (stagger delay 100ms) — editable name, dates, description
6. `SizedBox(height: 16)`
7. `EventDangerSection` (stagger delay 200ms) — delete event (creator-only)
8. `SizedBox(height: 32)` (scroll buffer)

Route: `/group/:gid/event/:eid/settings` — slide-right transition (matches all other settings screens).

Stagger animation: `flutter_animate` `.fadeIn(delay: Nms).slideY(begin: 0.1)`. Section delays: 100ms, 200ms. Duration: 400ms. Curve: Curves.easeOutCubic. Source: CONTEXT.md established patterns.

## Component Contracts

### EventExpenseHero (refresh)

Changes: Replace `CircularProgressIndicator` loading state inside card with `SkeletonLoader` shimmer row (height 80dp). All token references already use `AppColorTokens.light.*` — confirm no hardcoded Color() literals. Add `member count` metric if event has participants: "N members" next to "N expenses" in a row below the amount.

No layout structure changes — overline, animated total, supporting text.

### SmartModuleCard (refresh)

Each card: `radiusLarge` (16dp) border radius. Background: `cardSurface`. Border: 1dp `border`. Accent dot: module-specific token (moduleLedger = teal, all others = gray-500).

Module order (fixed): Ledger → Gear → Logistics → Vault → Activity → Memories.

Card tap: `OpenContainer` `ContainerTransform` — matches existing Phase 20 pattern. Do not change transition mechanism.

Card states:
- Enabled: full opacity, accent icon, summary text
- Disabled (module off): same layout, `textMuted` icon color, "Not enabled" summary text, tap still navigates

### EventInfoSection (new widget)

Container decoration: `cardSurface` background, `border` border (1dp), `radiusLarge` (16dp) border radius, `AppShadowTokens.standard.flat` shadow. Internal padding: 16dp.

Fields:
- Event name: text input, `inputFillWarm` fill, `borderWarm` border, `focusBorderWarm` focus — matches app-wide input theme
- Start date / End date: read-only tappable fields (show DatePicker on tap), same input decoration as text inputs
- Description: multi-line text input, maxLines: 4, same decoration

Section header: 13sp / weight 700 / textSecondary / letterSpacing 0.5 — "EVENT DETAILS" overline. Matches GroupInfoSection overline pattern.

Save button: full-width, 52dp height, primary gradient background (primaryGradient), white text "Save Changes" — weight 700 / 16sp.

### EventDangerSection (new widget — mirrors GroupDangerSection)

Container decoration: `cardSurface` background, `error` border (1dp, opacity 0.3), `radiusLarge` border radius, `AppShadowTokens.standard.flat` shadow. Internal padding: 16dp.

Section header overline: "DANGER ZONE" — 13sp / weight 700 / errorText (#B91C1C) / letterSpacing 0.5.

Delete event button: text button style, `errorText` (#B91C1C) foreground, `Iconsax.trash` leading icon, label "Delete event". Visible only to creator. If non-creator: omit entire section.

Balance-gate warning: if event has unsettled balances, show amber warning row above delete button. Icon: `Iconsax.warning_2` / `warning` (#F59E0B). Text: "This event has unsettled balances." — 13sp / weight 400 / textSecondary. Delete button remains tappable but dialog shows additional warning.

## Interaction Contracts

### Navigation
- Gear icon in dark header → `context.push('/group/$groupId/event/$eventId/settings')` — slide-right transition
- Back button in EventSettingsScreen → `context.pop()` — same slide-right reversal
- Module card tap → `OpenContainer` ContainerTransform to respective module route (existing pattern, do not change)
- FAB → `context.push('/group/$groupId/event/$eventId/ledger/add')` (existing, do not change)
- "Go Home" on not-found → `context.go('/home')`

### Haptics
- Gear icon tap: `HapticService.medium()`
- FAB tap: `HapticService.medium()` (existing — confirm present)
- Delete event tap: `HapticService.medium()`
- Save Changes tap: `HapticService.light()`
- Module card tap: `HapticService.light()` (confirm existing pattern)

### Animations
- EventSettingsScreen section entrance: `flutter_animate` `.fadeIn().slideY(begin: 0.1)` — delays 100ms / 200ms, duration 400ms, curve easeOutCubic
- EventExpenseHero amount counter: `TweenAnimationBuilder` 0→total, 800ms, easeOutCubic (existing — do not change)
- Module grid stagger: 80ms between cards, 400ms duration (existing EventModuleList — do not change)
- Gear icon button: no animation required; standard ink splash from IconButton

### Loading States
- EventCommandCenter loading: `SkeletonLoader.dashboardHero()` + `SkeletonLoader.cardList(count: 6)` — existing pattern, do not change
- EventSettingsScreen loading: `SkeletonLoader.generic(count: 3)` with back button visible — matches GroupSettingsScreen loading pattern
- EventExpenseHero inner loading: replace CircularProgressIndicator with `SkeletonLoader` shimmer row (height: 80dp) — source: CONTEXT.md discretion

### Error States
- Event not found: full `EmptyStateView` with `Iconsax.warning_2` / textSecondary icon color — existing, do not change
- Settings load error: inline column (icon + heading + body + TextButton retry) — matches GroupSettingsScreen error pattern
- Save mutation error: `ScaffoldMessenger.of(context).showSnackBar(...)` with floating SnackBar — dark background (#111827), white text, 12dp radius
