- Define a record type: `typedef ProfileStats = ({int groupCount, int eventCount, Decimal totalSpent});`
- Import `decimal` package, `group_provider.dart`, `event_provider.dart`, `group_balance_provider.dart`
- Create `final profileStatsProvider = Provider<AsyncValue<ProfileStats>>((ref) { ... });`
- Follow the exact pattern from `groupBalancesProvider` (Provider.family body with ref.watch in loops):
  1. `ref.watch(userGroupsProvider)` — if loading and no value, return `AsyncValue.loading()`. If error, return `AsyncValue.error(...)`.
  2. Extract `groups` list. `groupCount = groups.length`.
  3. Loop over groups: for each `group`, `ref.watch(groupEventsProvider(group.id))` to get events count, and `ref.watch(groupBalancesProvider(group.id))` to get `totalSpent`.
  4. Track `anyLoading` bool. Sum `eventCount` and `totalSpent` (using `Decimal` addition).
  5. If `anyLoading` and all sums are zero, return `AsyncValue.loading()`.
  6. Return `AsyncValue.data((groupCount: groups.length, eventCount: eventCount, totalSpent: totalSpent))`.

  ```dart
  Future<void> propagateDisplayName(String displayName) async {
    try {
      final uid = FirebaseConfig.currentUid;
      if (uid == null) return;
      final db = FirebaseConfig.firestore;
      final groupsSnap = await db.collection('groups')
          .where('memberIds', arrayContains: uid)
          .get();
      final batch = db.batch();
      for (final groupDoc in groupsSnap.docs) {
        final membersSnap = await db
            .collection('groups')
            .doc(groupDoc.id)
            .collection('members')
            .where('userId', isEqualTo: uid)
            .get();
        for (final memberDoc in membersSnap.docs) {
          batch.update(memberDoc.reference, {'displayName': displayName});
        }
      }
      await batch.commit();
    } catch (_) {
      // Silently fail per D-15 — Firestore offline persistence handles retry
    }
  }
  ```

  ```dart
    setState(() => _isSaving = true);
    HapticService.medium();
    final stopwatch = Stopwatch()..start();
    await widget.onSave(trimmed);
    final elapsed = stopwatch.elapsedMilliseconds;
    if (elapsed < 600) {
      await Future.delayed(Duration(milliseconds: 600 - elapsed));
    }
    if (!mounted) return;
  ```
