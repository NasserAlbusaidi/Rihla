## Spacing Scale

Declared values — all are multiples of 4, drawn from `AppSpacingTokens.standard`:

| Token | Value | Usage |
|-------|-------|-------|
| space4 | 4dp | Icon gaps, stat card inner spacing (value-to-label gap) |
| space8 | 8dp | Compact element spacing, name-to-edit-affordance gap |
| space12 | 12dp | Horizontal padding inside stat cards |
| space16 | 16dp | Default section padding, stat card vertical padding |
| space20 | 20dp | Identity section top padding, bottom sheet content padding |
| space24 | 24dp | Between identity section and stats row, screen horizontal padding |
| space32 | 32dp | Between stats row and bottom content, bottom sheet top padding |

Exceptions:
- Initials circle on profile screen: 64dp diameter (not a spacing value, component size)
- Initials circle on home header: 32dp diameter (component size)
- Touch targets: minimum 48dp for all tappable elements (WCAG compliant)
- Button height: 52dp (from `AppSpacingTokens.standard.buttonHeight`)
- Bottom sheet top radius: 28dp (established `showModalBottomSheet` pattern in home_screen.dart)

> Source: `lib/core/theme/tokens/spacing_tokens.dart`, RESEARCH.md Pattern 3, CONTEXT.md D-04, D-11

## Typography

All type uses Plus Jakarta Sans via `GoogleFonts.getFont('Plus Jakarta Sans', ...)`.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Stat number | 22sp | w800 | 1.1 | Big number in stat cards (group count, event count, OMR spending) |
| Body / name display | 16sp | w600 | 1.4 | Display name below initials circle, bottom sheet text field value |
| Label / section header | 12sp | w600 | 1.3 | Stat card labels ("Groups", "Events", "Spent"), section header uppercase text |
| Caption | 11sp | w600 | 1.2 | Stat card labels with letterSpacing: 0.5 |

Two weights only: **w600** (body, labels, captions) and **w800** (stat numbers).

Section header pattern: 11sp, w600, `textSecondary` color, `letterSpacing: 1.5`, UPPERCASE — matches established pattern in `settings_screen.dart` and all module screens.

> Source: RESEARCH.md Code Examples (stat card widget), `lib/core/theme/app_theme.dart` text theme, CONTEXT.md Claude's Discretion

## Color

All colors via `AppColorTokens.light.*` — CI blocks hardcoded `Color(0xFF...)` literals.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | `scaffoldBackground` | #FFFFFF | Screen background |
| Secondary (30%) | `cardSurface` | #F8F9FA | Stat card backgrounds, bottom sheet surface |
| Accent — terracotta (10%) | `focusBorderWarm` | #CC6B49 | Initials circle background (64dp + 32dp), active text field focus border in bottom sheet |
| Accent — teal | `primary` | #0D7B74 | Stat number accent for "Groups" card, Save button, checkmark icon on save success |
| Accent — emerald | `successText` | #047857 | Stat number accent for "Events" card |
| Accent — teal dark | `primaryDark` | #0A6B65 | Stat number accent for "Spent" card (differentiation from Groups) |
| Destructive | `errorText` | #B91C1C | Not used in Phase 25 (no destructive actions) |

Additional color assignments:
- Initials circle text (white on terracotta): `textOnPrimary` (#FFFFFF) — WCAG AA large verified
- Display name text: `textPrimary` (#111827) — 17.15:1 contrast on white
- Stat card label text: `textSecondary` (#6B7280) — 5.74:1 on cardSurface (#F8F9FA)
- Section header text: `textSecondary` (#6B7280)
- "Set your name" prompt (empty state): `primary` (#0D7B74) — tappable link style
- Bottom sheet background: `cardSurface` (#F8F9FA)
- Input fill (bottom sheet text field): `inputFillWarm` (#F5EDE1)
- Input border (enabled): `borderWarm` (#E5D5C0)
- Input border (focused): `focusBorderWarm` (#CC6B49)

Accent reserved for:
- `focusBorderWarm` (terracotta): initials circles only (64dp profile + 32dp header)
- `primary` (teal): Groups stat number, Save button, checkmark success icon, "Set your name" prompt
- `successText` (emerald): Events stat number
- `primaryDark` (dark teal): Spent stat number

> Source: CONTEXT.md D-04, D-09; RESEARCH.md Pattern 4, Pitfall 4, Code Examples; `lib/core/theme/tokens/color_tokens.dart`

## Screen Layout Contract

### Profile Screen (`/profile`)

```
ProfileScreen
├── Scaffold (scaffoldBackground)
│   └── SingleChildScrollView
│       └── Column (padding: horizontal 24dp)
│           ├── SizedBox(height: 20dp)           — top breathing room
│           ├── [Identity Section]               — fadeIn(delay: 100ms) + slideY(begin: 0.1)
│           │   ├── Center
│           │   │   ├── InitialsCircle(size: 64dp, bg: focusBorderWarm, text: textOnPrimary)
│           │   │   ├── SizedBox(height: 12dp)
│           │   │   ├── [IF name set] Text(displayName, 16sp/w600/textPrimary)
│           │   │   │   + Row with edit icon (Iconsax.edit_2, 16dp, textSecondary)
│           │   │   └── [IF name empty] GestureDetector → "Set your name" (16sp/w600/primary)
│           │   └── SizedBox(height: 8dp)         — below name, above section gap
│           ├── SizedBox(height: 24dp)            — identity-to-stats gap
│           ├── [Stats Section]                  — fadeIn(delay: 200ms) + slideY(begin: 0.1)
│           │   ├── [Section header: "YOUR JOURNEY" — 11sp/w600/textSecondary/letterSpacing:1.5]
│           │   ├── SizedBox(height: 12dp)
│           │   └── Row(children: 3 × StatCard, gap: 8dp)
│           │       ├── StatCard("N", "Groups", primary)
│           │       ├── StatCard("N", "Events", successText)
│           │       └── StatCard("OMR N.NNN", "Spent", primaryDark)
│           └── SizedBox(height: 32dp)            — bottom padding
```

### Stat Card Internal Layout

```
Expanded → Container(
  padding: vertical 16dp / horizontal 12dp,
  decoration: cardSurface bg, BorderRadius.circular(16), shadowRaised,
)
└── Column(mainAxisSize: min)
    ├── Text(value, 22sp/w800/accent)
    ├── SizedBox(height: 4dp)
    └── Text(label, 11sp/w600/textSecondary, letterSpacing: 0.5, textAlign: center)
```

Spending display format: `"OMR 45.250"` — currency prefix on value string, no currency in label.
Groups stat: integer string e.g. `"3"`.
Events stat: integer string e.g. `"12"`.

### Loading State (stats while profileStatsProvider is loading)

Replace the 3 stat card values with skeletonizer shimmer over the same card layout. Use `Skeletonizer` wrapping the stats row — the real layout bones animate as skeleton. Fall back gracefully: show last known data if available, shimmer only on initial load.

### Bottom Sheet: Edit Name

```
showModalBottomSheet(
  isScrollControlled: true,
  backgroundColor: cardSurface,
  shape: RoundedRectangleBorder(
    borderRadius: BorderRadius.vertical(top: Radius.circular(28)),
  ),
)
└── EditNameBottomSheet (StatefulWidget)
    └── Padding(bottom: MediaQuery.viewInsetsOf(context).bottom)
        └── Column(padding: horizontal 24dp / top 32dp / bottom 24dp)
            ├── Handle bar (40×4dp, borderRadius: 2dp, color: border) — centered
            ├── SizedBox(height: 20dp)
            ├── Text("Edit Name", 16sp/w600/textPrimary)
            ├── SizedBox(height: 16dp)
            ├── TextField(
            │     fill: inputFillWarm,
            │     border: borderWarm,
            │     focusBorder: focusBorderWarm (2dp),
            │     labelText: "Display name",
            │     hintText: "e.g. Nasser",
            │   )
            ├── SizedBox(height: 24dp)
            └── SaveButton (full-width, height: 52dp, borderRadius: 12dp)
                ├── [idle]   → Text("Save Name", 16sp/w700/textOnPrimary) — primary bg
                ├── [saving] → SizedBox(20dp) CircularProgressIndicator(color: textOnPrimary, strokeWidth: 2)
                └── [saved]  → Icon(Icons.check_rounded, 20dp, textOnPrimary) — briefly shown
```

Save flow timing: saving state shown for minimum 600ms (to avoid flicker). Checkmark shown for 800ms, then sheet closes automatically.

Save button disabled when text field is empty (after trim).

### Home Header: Initials Avatar (D-11)

Add to the home dashboard header row's trailing area. Position: right-most element in the header row.

```
GestureDetector(
  onTap: () => context.push('/profile'),
  child: InitialsCircle(size: 32dp, bg: focusBorderWarm, text: textOnPrimary),
)
```

Touch target: wrap in SizedBox(48dp × 48dp) for minimum touch area compliance.

## Interaction Contract

| Interaction | Trigger | Response | Haptic |
|-------------|---------|----------|--------|
| Navigate to profile | Tap initials avatar in home header | `context.push('/profile')`, slide-right | `HapticService.lightImpact()` |
| Navigate to profile via bottom nav | Tap Profile tab (index 3) | Replace `_PlaceholderTab()` with `ProfileScreen()` | None (standard tab switch) |
| Open edit name sheet | Tap display name row OR "Set your name" prompt | `showModalBottomSheet(...)` | `HapticService.selectionClick()` |
| Type in name field | Text input | Real-time: enable/disable Save button (trim non-empty) | None |
| Tap Save | Button tap (enabled state) | → saving state → Firestore batch → checkmark → auto-close | `HapticService.mediumImpact()` on save tap; `HapticService.lightImpact()` on checkmark |
| Stats load | Provider resolves | Skeletonizer → real data (fade transition via flutter_animate) | None |

### Entrance Animations

```dart
// Identity section
_buildIdentitySection()
    .animate()
    .fadeIn(duration: 250.ms, delay: 100.ms)
    .slideY(begin: 0.1, duration: 250.ms, curve: Curves.easeOutCubic)

// Stats section
_buildStatsSection()
    .animate()
    .fadeIn(duration: 250.ms, delay: 200.ms)
    .slideY(begin: 0.1, duration: 250.ms, curve: Curves.easeOutCubic)
```

### Navigation Back Button

`ProfileScreen` must work as both a routed screen (from header avatar — has back button) and a tab (from bottom nav — no back button). Conditional: `if (GoRouter.of(context).canPop()) BackButton()`.

## Empty States

| State | Visual | Copy |
|-------|--------|-------|
| Name not set | `?` in initials circle | "Set your name" (tappable, primary color, triggers edit sheet immediately) |
| Stats loading | Skeletonizer over stat card row | No copy — skeleton shimmer is self-explanatory |
| Stats all zero (new user) | 3 stat cards showing "0", "0", "OMR 0.000" | No special empty state — zeros are valid data |

- Name field empty (validation): Save button simply disabled — no error text shown. Empty field cannot be submitted.
