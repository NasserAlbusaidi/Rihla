**Production fix (lib/main.dart):**

1. Add import: `import 'core/providers/app_bootstrap_provider.dart';`
2. In `SafarApp.build()`, add `ref.watch(appBootstrapProvider);` on the line after `final settings = ref.watch(settingsProvider);`
   - This is a `Provider<void>` so the return value is discarded. The watch activates the provider's `ref.listen` callback.
   - Do NOT assign to a variable — the void return is intentional.

The full build method should read:
```dart
@override
Widget build(BuildContext context, WidgetRef ref) {
  final router = ref.watch(routerProvider);
  final settings = ref.watch(settingsProvider);
  // Activate bootstrap listeners (notification sync, etc.)
  ref.watch(appBootstrapProvider);

  return MaterialApp.router(
    title: 'Safar',
    debugShowCheckedModeBanner: false,
    theme: AppTheme.lightTheme,
    darkTheme: AppTheme.darkTheme,
    themeMode: settings.theme,
    routerConfig: router,
  );
}
```
