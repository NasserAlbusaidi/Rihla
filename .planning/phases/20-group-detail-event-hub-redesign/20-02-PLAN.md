### Task 02 — Redesign EventExpenseHero and EventModuleList
**Wave:** 1 | **Reqs:** SCRN-02
**Input:** Updated `event_keys.dart` (Task 01), existing `event_expense_hero.dart` (181 lines), `event_module_list.dart` (336 lines)
**Output:** Light-themed expense hero, 2x3 module grid with corrected colors and Activity card

**Steps:**

**A. Redesign EventExpenseHero** (`lib/features/events/screens/event_expense_hero.dart`):
1. Replace the dark gradient card with a light surface card per D-14 and design spec:
   - Container background: `AppColors.surface` (not `darkHeaderGradient`)
   - Border: `Border.all(color: AppColors.border)`
   - BorderRadius: `AppColors.radiusLarge` (20dp)
   - BoxShadow: `AppColors.shadowRaised`
   - Remove the `ClipRRect`, `Stack`, and decorative circle overlay
2. Redesign the content layout:
   - Overline: "TOTAL EXPENSES" in `TextStyle(fontSize: 10, fontWeight: FontWeight.w700, color: AppColors.textMuted, letterSpacing: 0.5)`. This is decorative (overline label), textMuted is acceptable per WCAG rules.
   - Total amount: Use the existing `TweenAnimationBuilder<double>` pattern but change text style to `TextStyle(fontSize: 36, fontWeight: FontWeight.w800, color: AppColors.textPrimary)` (was white on dark). Key this with `EventKeys.expenseHeroTotal`.
   - Expense count: `TextStyle(fontSize: 12, fontWeight: FontWeight.w600, color: AppColors.textSecondary)` (was white38).
   - Add "+ Add Expense" chip button: `ActionChip(label: Text('+ Add Expense'), backgroundColor: AppColors.primary, labelStyle: TextStyle(color: Colors.white, fontWeight: FontWeight.w700), onPressed: onTap)`. Key with `EventKeys.addExpenseChip`. Position at the top-right of the card using a Row with Spacer or Align.
3. Keep the `EventKeys.spendingHero` key on the outer GestureDetector (preserve existing test discoverability).
4. Keep `eventExpensesProvider` watch — data source unchanged.
5. Remove the `Icon(Iconsax.wallet_3)` in the old header row and the `Icon(Iconsax.arrow_right_3)` trailing chevron.
6. Remove `height: 140` fixed constraint — let the card size to content. Add padding `EdgeInsets.all(AppColors.space16)`.

**B. Redesign EventModuleList** (`lib/features/events/widgets/event_module_list.dart`):
1. **Add Activity card**: The current code does not include an Activity module card. Add an `_addActivityCard` method following the same pattern as `_addMemoriesCard`:
   ```
   cards.add(_ModuleCardConfig(
     widgetKey: EventKeys.activityCard,
     icon: Iconsax.activity,
     title: 'Activity',
     description: 'Timeline logs',
     color: AppColors.moduleActivity,  // gray-500 per D-12
     onTap: () => context.push('/group/$groupId/event/$eventId/activity'),
     priority: 10,
     isEmpty: true,
   ));
   ```
   Activity count wiring is deferred per research Open Question 3.

2. **Correct all module colors** to match AppColorTokens.light (fixing the critical color gap identified in research):
   - Ledger: change `AppColors.accentSecondary` to `AppColors.moduleLedger` (line ~162)
   - Gear: change `AppColors.amber` / `AppColors.accentSecondary` to `AppColors.moduleGear` (line ~203)
   - Logistics: change `AppColors.sky` to `AppColors.moduleLogistics` (line ~237)
   - Vault: change `AppColors.indigo` to `AppColors.moduleVault` (line ~271)
   - Memories: change `AppColors.mint` to `AppColors.moduleMemories` (line ~284)
   - Activity (new): use `AppColors.moduleActivity`

3. **Replace priority sorting with fixed order** per D-13 and Pitfall 6:
   - Remove `cards.sort((a, b) => b.priority.compareTo(a.priority));` (line ~94)
   - Instead, build cards in fixed order: Ledger, Gear, Logistics, Vault, Activity, Memories. The `_add*Card` methods are already called in this order (except Activity is new); just remove the sort.

4. **Convert Column to a widget that returns a list of cards** for grid consumption:
   - Change the `build` return from `Column(children: [...SmartModuleCard...])` to returning a `Column` but structured so the parent (EventCommandCenter) can pass it into a `SliverGrid` wrapper.
   - Actually, the simplest approach per research: change EventModuleList to expose a method or just change the return to a `GridView.count(crossAxisCount: 2, shrinkWrap: true, physics: NeverScrollableScrollPhysics(), crossAxisSpacing: 12, mainAxisSpacing: 12, childAspectRatio: 2.0)` containing the SmartModuleCards.
   - Keep the `flutter_animate` stagger animations on each card but adjust delay indices for the grid layout.
   - Key the GridView with `EventKeys.moduleGrid`.

5. **Remove priority field from _ModuleCardConfig** — no longer used since sort is removed.

**Verify:** `flutter test test/features/events/event_command_center_test.dart` — the "TOTAL EXPENSES" label tests and module grid tests should go green. `flutter test test/features/ledger_test.dart` — should pass unaffected (ledger tests use `LedgerKeys.spendingLabel`, not `find.text('SPENDING')`).

### Task 03 — Rebuild EventCommandCenter + OpenContainer on HomeScreen
**Wave:** 1 | **Reqs:** SCRN-02
**Input:** Redesigned `EventExpenseHero` and `EventModuleList` (Task 02), existing `event_command_center.dart` (144 lines), `home_screen.dart`
**Output:** EventCommandCenter using CustomScrollView, HomeScreen GroupCard wrapped in OpenContainer

**Steps:**

**A. Rebuild EventCommandCenter** (`lib/features/events/screens/event_command_center.dart`):
1. Replace the current `Column > SingleChildScrollView > Column` structure with `CustomScrollView` + slivers for smoother scrolling (matching Phase 18 home dashboard pattern):
   ```
   body: CustomScrollView(
     slivers: [
       // ModuleHeader as SliverToBoxAdapter
       SliverToBoxAdapter(child: ModuleHeader(...)),
       // OfflineBanner
       SliverToBoxAdapter(child: OfflineBanner()),
       // Expense Hero
       SliverPadding(
         padding: EdgeInsets.fromLTRB(space24, space20, space24, space24),
         sliver: SliverToBoxAdapter(child: EventExpenseHero(...)),
       ),
       // Module Grid — EventModuleList now returns a GridView wrapped in SliverToBoxAdapter
       SliverPadding(
         padding: EdgeInsets.symmetric(horizontal: space24),
         sliver: SliverToBoxAdapter(child: EventModuleList(...)),
       ),
       // Bottom padding
       SliverToBoxAdapter(child: SizedBox(height: space32)),
     ],
   )
   ```
2. Replace the loading `CircularProgressIndicator` with skeleton composites:
   - `SliverToBoxAdapter` containing: `ModuleHeader(title: '', subtitle: '', useDarkTheme: true)`
   - `SliverPadding` with `SliverToBoxAdapter` containing: `SkeletonBlock` for hero area (~120dp), `SizedBox(height: space24)`, 2x3 grid of `SkeletonBlock` cards matching the module grid dimensions.
3. Keep all existing provider watches (`eventDetailProvider`, `groupDetailProvider`).
4. Keep the `FloatingActionButton` for adding expenses.
5. Keep the not-found `EmptyStateView` fallback.

**B. Add OpenContainer on HomeScreen** (`lib/features/home/screens/home_screen.dart`):
1. Add import: `import 'package:animations/animations.dart';`
2. In the Group Cards section (around line 153-173), find the `FadeInList(children: groups.map((group) { ... }))` block. Currently each group renders:
   ```dart
   TapBounce(
     onTap: () => context.push('/group/${group.id}'),
     child: GroupCard(group: group, onTap: () => context.push('/group/${group.id}')),
   )
   ```
3. Replace with `OpenContainer<void>` per D-04, D-05, D-06 and research Pattern 4:
   ```dart
   OpenContainer<void>(
     closedColor: Colors.transparent,
     openColor: AppColors.background,
     closedElevation: 0,
     openElevation: 0,
     closedShape: RoundedRectangleBorder(
       borderRadius: BorderRadius.circular(AppColors.radiusLarge),
     ),
     openShape: const RoundedRectangleBorder(),
     transitionDuration: const Duration(milliseconds: 400),
     transitionType: ContainerTransitionType.fade,
     useRootNavigator: false,
     closedBuilder: (context, openContainer) => GroupCard(
       group: group,
       onTap: openContainer,
     ),
     openBuilder: (context, closeContainer) => GroupDetailScreen(
       groupId: group.id,
     ),
   )
   ```
4. Remove the `TapBounce` wrapper — OpenContainer handles the tap. Keep the `Padding(bottom: space8)` wrapper.
5. Import `GroupDetailScreen` in home_screen.dart: `import '../../groups/screens/group_detail_screen.dart';`
6. The `FadeInList` wrapping is fine — OpenContainer sits inside the FadeInList item, not the other way around.
7. Per research Pitfall 1: Accept that the URL does not update during OpenContainer transition. GoRouter's `/group/:gid` route remains for all other navigation paths (deep links, back from sub-routes). This is documented as an accepted limitation per D-06 discretion.

**Verify:** `flutter test` — full test suite green. The home_screen tests may need review if they assert on `TapBounce` presence inside group cards (check if they do). The OpenContainer widget renders the GroupCard via `closedBuilder` — existing tests finding `GroupCard` should still find it.
