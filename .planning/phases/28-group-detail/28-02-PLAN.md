    ```dart
    RefreshIndicator(
      color: AppColorTokens.light.primary,
      backgroundColor: AppColorTokens.light.cardSurface,
      onRefresh: () async {
        // Invalidate Firestore-backed stream providers (NOT groupBalancesProvider — it's a computed Provider.family that auto-recomputes)
        ref.invalidate(groupDetailProvider(groupId));
        ref.invalidate(groupEventsProvider(groupId));
        ref.invalidate(groupMembersProvider(groupId));
        ref.invalidate(groupActivityProvider(groupId));
        ref.invalidate(groupSettlementsProvider(groupId));
        // Brief delay for streams to re-establish before dismissing indicator
        await Future.delayed(const Duration(milliseconds: 500));
      },
      child: SingleChildScrollView(
        physics: const AlwaysScrollableScrollPhysics(), // Required for RefreshIndicator to work even when content fits screen
        padding: const EdgeInsets.symmetric(horizontal: 16),
        child: Column(
          // ... existing content
        ),
      ),
    ),
    ```

    IMPORTANT: Add `physics: const AlwaysScrollableScrollPhysics()` to the `SingleChildScrollView`. Without this, `RefreshIndicator` does not activate when content fits within the viewport. Also add import for `groupSettlementsProvider` if not already imported from `group_balance_provider.dart`.

    In `_buildEventsSection`, replace the bare `Column` wrapping event cards with `FadeInList`. The current code structure is:

    Replace with:
    ```dart
    return FadeInList(
      children: [
        for (int i = 0; i < events.length; i++)

            child: OpenContainer<void>(
              closedColor: Colors.transparent,

              transitionDuration: const Duration(milliseconds: 400),
              transitionType: ContainerTransitionType.fade,
              useRootNavigator: false,
              closedBuilder: (context, openContainer) => EventCard(
                event: events[i],
                personalBalance: userEventBreakdown[events[i].id],

                groupId: groupId,
                eventId: events[i].id,

          ),
    ```

    Key notes:
    - `FadeInList` wraps children in its own `Column` internally — remove the outer `Column`

    - The `FadeInList` MUST be inside `_buildEventsSection` which watches `groupEventsProvider`, NOT inside any widget watching `groupBalancesProvider`. This prevents animation replay on balance updates (RESEARCH Pitfall 2)
