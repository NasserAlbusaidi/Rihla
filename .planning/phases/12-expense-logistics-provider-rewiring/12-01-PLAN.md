<objective>
Fix payer-override visibility and currency derivation in expense forms by replacing dead `userTripsProvider` (Trip/SQLite) lookups with direct Event field access, then delete `userTripsProvider`.

Purpose: The payer-override dropdown is always hidden because `isLeader` reads from a dead SQLite provider that always returns null. Currency always falls back to 'OMR' for the same reason. Both bugs block FIN-01 (per-event balance attribution via payer selection).

Output: Working payer-override selector visible to event creators, correct currency derivation from Event model, `userTripsProvider` deleted, and widget tests proving both behaviors.
</objective>
