## Integration Issues (Ranked by Severity)

### HIGH — Functional regression for all users

**1. Gear screen write mutations are no-ops**
- Files: `lib/features/gear/screens/gear_screen.dart` lines 578-642
- All write paths (`_addItem`, `_confirmDelete`, `_togglePacked`, `_handleMenuAction`) log to debugPrint and return
- Read path works (Firestore stream via `eventGearItemsProvider`). Camping seeding works (`EventService._seedCampingGear`)
- **Affects:** EVT-04 (partial), EVT-08

**2. Payer-override selector permanently hidden**
- Files: `lib/features/ledger/widgets/split_scope_selector.dart:394`, `lib/features/ledger/screens/edit_expense_sheet.dart:361`
- `isLeader` derives from `trip?.leaderId == currentUser?.uid` via `userTripsProvider` (SQLite)
- For all Firestore events, `trip` is `null` → `isLeader` = `false` → dropdown never rendered
- **Fix:** Derive from `event.createdBy == currentUser?.uid` instead
- **Affects:** EVT-08, FIN-01

### MEDIUM — Silent incorrect behavior

**3. _tripCurrency always returns 'OMR' for Firestore events**
- Files: `lib/features/ledger/screens/add_expense_screen.dart:63-75`, `edit_expense_sheet.dart:51-59`
- Same root cause: `userTripsProvider` returns empty for Firestore events
- **Fix:** Read currency from event or group object instead
- **Affects:** EVT-08 (multi-currency)

**4. LogisticsScreen removeMember is a no-op**
- File: `lib/features/logistics/screens/logistics_screen.dart:157-160`
- Callback logs "removeMember not supported in legacy screen" and returns
- **Affects:** EVT-08

### LOW — Dead code / stale documentation

**5.** 3 orphaned providers: `tripUnifiedLedgerProvider`, `tripSeedProvider`, `tripSubGroupsProvider`
**6.** Stale comment in `auth_provider.dart` referencing deleted `firebase_auth_provider.dart`
